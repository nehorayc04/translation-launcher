# The Witcher 3 — תרגום 1,447 שורות מ**ערבית** לעברית

לשורות האלה מקור-האנגלית הגיע פגום בחילוץ (ג'יבריש), אבל ה**ערבית תקינה** — אז מתרגמים מהערבית.
עולם פנטזיה (המכשף/וויצ'ר): גראלט, סירי, ינפר, נילפגארד, נוביגרד.

## הלולאה (חזור עד "All done!")
```
python get_batch.py 40      # כותב current_batch.json = {id: {ar}}
# תרגם כל 'ar' לעברית, שים בערך
python merge_batch.py       # מאמת + ממזג
```

## כללים (merge_batch דוחה שורה שמפרה — היא תחזור בסבב הבא)
1. תרגם את ה-`ar` (ערבית) לעברית **טבעית וזורמת**, תואמת-תקופה (פנטזיה ימי-ביניים).
2. **בלי אף אות ערבית** בתוצאה, בלי ניקוד, בלי ג'יבריש.
3. **שמור כל תג/placeholder מה-ar מילה-במילה:** `<br>`, `<i>`, `</i>`, `<font...>`, `{...}`, `%d`, `&ent;` — אותו מספר ואותו סוג.
4. שמות בתעתיק עברי קנוני: גראלט · סירי · ינפר · טריס · וזמיר · רגיס · נילפגארד · נוביגרד · ולן · סקליגה · קאר מורהן · טוסאן · רדאניה.
5. אל תמציא ואל תדלג; אל תיגע בקבצים אחרים ואל תערוך את `to_translate.json`.

## סיום
כשמודפס **"All done!"** — סיימת.
