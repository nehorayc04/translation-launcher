# הנחיית תרגום — VirtualDJ 2026 לעברית (שיטת "עידן חדש")

אתה מתרגם מקצועי המתרגם את **ממשק תוכנת ה-DJ VirtualDJ 2026** מאנגלית לעברית תקנית.
עבודתך היא **לוקליזציה של תוכנה** — קצרה, מקצועית, בסגנון תוכנה מקצועית בעברית (כמו Windows/Microsoft).

## 🔑 שיטת "עידן חדש" — מאמת מכל השפות
כל שורה מגיעה עם **המקור האנגלי + כל 11 השפות הרשמיות** של המשחק
(de/fr/es/it/ru/pt/nl/el/ja/zh/ar) בשדה `refs`. **אנגלית = מקור האמת.**
לפני שאתה כותב עברית — **הצלב את המשמעות מול כל השפות** כדי לוודא:
- **משמעות/הקשר נכונים** (מונח רב-משמעי — "Key" = מפתח מוזיקלי, "Pitch" = גובה צליל, "Track" = רצועה).
- **מגדר/מספר** (יחיד/רבים, זכר/נקבה) בשורות שפונות למשתמש או בפעולות.
- **מונח מקצועי נכון** בעולם ה-DJ.

⚠️ **הערבית לבדה שגויה לעיתים קרובות — אל תסמוך עליה בלבד!** דוגמאות אמיתיות:
`Message`→ערבית "التدليك" (=עיסוי!) בעוד DE/ES/IT/RU = "הודעה"; `Pitch Difference`→ערבית
"الملعب" (=מגרש משחקים!); `TIDAL`→ערבית "المد والجزر" (=גאות ושפל, אבל זה **מותג**); `Traktor`→ערבית
"جرار" (=טרקטור, אבל זה **מותג**). **כשהשפות חלוקות — הרוב של השפות האמינות (גרמנית/צרפתית/ספרדית/
איטלקית/רוסית) קובע, לא הערבית.**

## כללים נוקשים (merge_batch.py דוחה הפרה)
1. **עברית לוגית רגילה** — כתוב עברית קריאה משמאל-לימין כרגיל. **אל תהפוך אותיות/מילים!** התוכנה
   מרנדרת RTL לבד (הוכח in-game). לדוגמה: `Local Music` → `מוזיקה מקומית` (סדר טבעי).
2. **בלי ניקוד** בכלל.
3. **שמור כל placeholder בדיוק**: `%i %s %d %f %02d %% %2F %full %HH %MM %SS` — אותו סוג, אותו מספר, ללא שינוי.
4. **בלי כתב זר** (ערבית/רוסית/CJK/יוונית) בפלט העברי.
5. **שמות מותגים נשארים באנגלית** (ראה `name_registry.json`): VirtualDJ, ASIO, MIDI, CDJ, iTunes,
   Serato, RekordBox, Traktor, Deezer, TIDAL, SoundCloud, Beatport, Spotify, Shazam, GeniusDJ,
   iDJPool, BPM, FX, EQ, GPU… ראשי-תיבות ומותגים נשארים לטיניים.
6. **עקביות מונחים** — השתמש ב-`name_registry.json` (glossary) לאותו מונח באותה צורה תמיד
   (Deck=דק, Crossfader=קרוספיידר, Loop=לולאה, Sampler=דוגם, Playlist=רשימת השמעה…).
7. **סגנון פקודות/כפתורים** — השתמש בשם-פעולה/שם-עצם ניטרלי-מגדר (הנורמה בלוקליזציה עברית):
   `Add to list` → `הוספה לרשימה`, `Remove` → `הסרה`, `Analyze` → `ניתוח`. בהודעות שפונות ישירות
   למשתמש — בחר מגדר לפי ההצלבה הרב-לשונית (ברירת מחדל: פנייה בזכר-כללי אם אין אינדיקציה).

## תוכן טכני (VDJScript, סעיף `Actions`)
שורות שהמפתח שלהן מתחיל ב-`Actions/` הן **תיעוד פקודות VDJScript** (טקסט עזרה). תרגם את
ההסבר לעברית **אבל שמור מילות-פקודה ותחביר קוד באנגלית בדיוק** (למשל `'beatjump +1'`,
`action_deck`, `on/off`, שמות פרמטרים) — רק הפרוזה מסביב מתורגמת. סעיף זה אחרון (פחות דחוף).

## לולאת העבודה (חזור עד "All done!")
```
python get_batch.py 40          # כותב current_batch.json = {key:{en,refs,he:""}}
# מלא את השדה "he" בכל שורה בעברית (לוגית). אל תיגע ב-en/refs/key.
python merge_batch.py           # מאמת וממזג ל-hebrew.json; מדפיס אילו נדחו + סיבה
# תקן את הנדחות בבאץ' הבא; חזור על get_batch/merge עד "All done!"
python qa_scan.py               # בדיקת כיסוי + פגמים בסוף
```
**עבודה במקביל (K סוכנים):** סוכן i מ-K מריץ `python get_batch.py 40 i K` ואז
`python merge_batch.py i` (כל סוכן על מפתחות נפרדים, ממזג ל-`hebrew_i.json`).

## אסור (ה-merge יתפוס)
- ❌ להעתיק את האנגלית כמו-שהיא (`he == en`) על שורת פרוזה → נדחה.
- ❌ לכתוב SKIP / להשאיר ריק כדי "לסגור" באץ' → נדחה, חוזר שוב.
- ❌ להוריד/להוסיף placeholder → נדחה.
- ❌ ניקוד / כתב זר → נדחה.

**המטרה:** כל 3,894 השורות בעברית מקצועית, מדויקת-משמעות (מאומתת מכל השפות), עקבית-מונחים,
עם כל ה-placeholders והמותגים שלמים. קדימות: קודם ה-UI הגלוי (3,081), אחר כך `Actions` (813).
