# מצב הצי — Fleet Dashboard (תוכנה נפרדת, אישית)

EXE יחיד שמציג בזמן אמת את כל זרמי התרגום/הביקורת — התקדמות, ביצועים, דוגמאות תרגום אחרונות,
ו**כל בעיה, אפילו הקטנה, עם הסיבה ומה עושים איתה**.

**מעוצב במדויק כמו הלאנצ'ר** (אותה משפחה, תוכנה אחרת — לא נוגע בו): אותו פונט **Heebo** (ה-TTF
מוטמעים ב-EXE), אותם משטחי זכוכית, אותו סרגל 72↔230 עם **מחוון זכוכית נודד** ופס-קצה זוהר, אותה
אנימציית מסך, אותו stagger, אותם **segmented controls** עם thumb זוהר מחליק, פס כותרת מותאם ללא
מסגרת, רקע ambient בצבע המבטא, ואותן **הגדרות** (רמת אנימציה, גודל טקסט, מצב סרגל, מבטא).
כל טוקן נשאב מ-`frontend/src/index.css` + `tailwind.config.js` — ראו את הטבלה בראש `ui.py`.

    dist\FleetDash.exe                  ← דאבל-קליק (קובץ אחד, בלי התקנה) · קיצור "מצב הצי" בשולחן
    python dash.py                      ← מהמקור
    python dash.py --view streams       ← נפתח ישר על מסך מסוים
    python dash.py --once               ← איסוף אחד כטקסט (אותם נתונים, בלי GUI)

בנייה: `..\..\.venv\Scripts\pyinstaller.exe --noconfirm --clean FleetDash.spec`
(חובה ה-venv של הפרויקט — שם יש PySide6.)

## המסכים (סרגל ימני)

| מסך | מה יש בו |
|---|---|
| **◈ סקירה** | כרטיס לכל משחק (אחוז, בר מדורג, נשארו, קצב, סיום משוער, גיל מיזוג, כפולות) + אזהרות דחופות + דוגמאות + ספקים. אפשר לכבות כל פאנל בהגדרות. |
| **≡ זרמים** | שורה לכל זרם: מצב צבעוני, התקדמות **במנה שלו**, נשאר, קצב, מתי הפלט זז, PID, סיבה. מסנן: הכל / בעיות / עובדים / סיימו. עמודות נבחרות בהגדרות. |
| **⚠ אזהרות** | כל ממצא עם דרגה, סיבה מדודה, ו"מה עושים". מסנן: הכל / תקלות / אזהרות. |
| **✎ תרגומים** | שורות שנכנסו לבנק: אנגלית, ואז עברית **לפני/אחרי** (או "אושר ללא שינוי"). מסנן: הכל / תיקונים בלבד. |
| **⚡ ביצועים** | תפוקה לפי ספק (חיים, שורות/דקה, חנוקים, נשאר) + לכל מכונה: מקום פנוי, מצב task, מצב VM, workers מיותרים. |
| **⚙ הגדרות** | להלן. |

## הגדרות

**מראה** — אנימציה (מלאה / רגילה / מופחתת / כבויה) · רקע החלון (זכוכית / אקריליק / מיקה / אטום —
טשטוש **אמיתי** של Windows דרך DWM) · צבע מבטא (6 גוונים מהפלטה של הלאנצ'ר) · גודל טקסט 75%–125%
בצעדי 5% · סרגל צד (נפתח במעבר עכבר / נעוץ פתוח / נעוץ מכווץ) · אפקט גל בלחיצה · פס כותרת מותאם.

**מה מוצג ומה מוסתר** — אילו משחקים מוצגים · אילו עמודות בטבלה · אילו פאנלים בסקירה · הסתרת ממצאי
מידע (429) · הסתרת זרמים שסיימו.

**רענון** — רענון מקומי 5–60 ש' · בדיקת מכונות 30–300 ש' · חלון חישוב הקצב 5–60 דק'.

הכול נשמר ב-`%LOCALAPPDATA%\FleetDash\prefs.json` (גם גודל ומקום החלון); היסטוריית הקצב ב-
`history.json`; קריסות ב-`dash.log`.

## מספרי זרמים (#)

לכל זרם יש **מספר קבוע** בעמודה הראשונה, כדי שאפשר יהיה להגיד "זרם 7" במקום `witcher3 · vm3 · groq`.
המספר מגיע מרישום מתמיד ב-`%LOCALAPPDATA%\FleetDash\stream_ids.json` — **לא** אינדקס שורה: סינון,
מיון או הסתרת משחק לא מזיזים אותו, ומספר לא ממוחזר. מכונה שתתווסף בעתיד תקבל את המספר הפנוי הבא.

## מה הוא בודק (כל בדיקה מחזירה סיבה)

זרם מת · תקוע · חנוק · כפילות תהליך · **חסר `corpus_<provider>.json`** (הזרם חזר לחלוקת md5%3
הישנה) · אפס תפוקה בחלון · מכונה לא נענתה (עם ספירת פעמים רצופות) · **worker legacy בלי ארגומנט
ספק** (משכפל עבודה) · workers של פרויקטים שסיימו שגוזלים מכסות API · מעט מקום בכונן · task השקה
מושבת/חסר · VM לא רץ · בנק פגום (NUL) · המיזוג קפוא · עבודה כפולה מצטברת · אין pusher / יש שניים.

## מצב מאגר (דור 2 של הצי) — `"pool": "<game>"` ב-`fleet_config.json`

כשמשחק עבר למאגר האחד, המכונות כבר לא מחזיקות מנה מראש ולא כותבות בנקים מקומיים — כל זרם הוא
**לקוח של התור**, בדיוק כמו טלפוני המתנדבים. לכן במצב הזה הלוח שואב מהמאגר ולא מהדיסק:

* **התקדמות המשחק** = `corpus_total` פחות מה שנשאר בתור (`open + claimed`) — מדויק, כי התור מחזיק
  רק את מה שעוד לא תורגם. ה**קצב** רוכב על מונה ה-`done` של התור עצמו (עולה תמיד).
* **התקדמות של זרם** = ה-`done` של אותו worker בתור, ו"מחזיק" = כמה שורות הוא תפוס עליהן **עכשיו**.
  ה-join נעשה לפי `cd-<COMPUTERNAME>-<provider>`; ה-COMPUTERNAME אינו השם הקצר שבקונפיג (האורח
  `vm2` מדווח `WIN11-VM-2`), ולכן הוא נעוץ לכל מכונה בשדה **`pool_id`** ולא מנוחש מהשם.
* **חיוּת** ממשיכה לבוא מבדיקת ה-ssh — רק היא יודעת להבדיל בין worker שקרס לבין worker שהספק
  פשוט מסרב לו.
* **טלפוני המתנדבים מופיעים בתוך שורת המשחק** ולא כשורה "קהילה" נפרדת — זה בדיוק המובן של מאגר
  אחד. `collect_cc` מדלגת על משחק שכבר מוצג ככה, אחרת אותו תור היה נספר פעמיים.
* **כללי הבנקים מושבתים** למשחק כזה (אין בנק, אין מיזוג, אין מנה) — אחרת היו נופלות שלוש
  התרעות שווא קבועות על צי בריא.
* **בדיקה חדשה: "חי אך לא מדווח למאגר"** — התהליך רץ אבל התור לא שמע ממנו יותר מ-lease אחד. זו
  התקלה השקטה של מצב מאגר, והיא בלתי-נראית לכל בדיקה אחרת.
* **הדוגמאות** נקראות מ-`samples.jsonl` שה-worker כותב ליד הלוג בכל הגשה (במצב מאגר אין בנק
  להשוות מולו). נקרא רק מהמכונה המקומית — קריאת ssh בכל טיק יקרה מהערך של הפיד.

## עובדות מימוש

* **שני קצבי רענון**: בנקים מקומיים (זול) מול בדיקת ssh לשש מכונות (יקר). כל פאנל מציג את **הגיל**
  של מה שהוא מראה, כדי שבדיקה ישנה לא תתחזה לנתון חי.
* **התקדמות "במנה"** (מצב מנות בלבד) = חיתוך בין קובץ המנה של הזרם
  (`fleet/shards/corpus_<machine>_<prov>.json`) לבין הבנק שלו — בדיוק מה שהזרם הזה עשה, לא מספר
  גלובלי.
* **הדוגמאות** מתעדכנות אחרי מיזוג; בפתיחה הפיד נזרע מהזנב של כל בנק (worker מוסיף מפתחות בסדר
  שבו הוא בנק, ו-dict בפייתון שומר סדר הכנסה → הזנב הוא הכי טרי).
* **תצורה**: `fleet_config.json`; עותק **ליד ה-EXE** מנצח את זה שבתוכו — אפשר לשנות מכונות/פורטים/
  ספים בלי בנייה מחדש.

## מלכודות שנפתרו בבנייה (לא לחזור אליהן)

1. **PowerShell הרס את ה-JSON של עצמו** — `Get-Content` מחזיר מחרוזות *מעוטרות* ו-`ConvertTo-Json`
   סירֵאל את כל ה-`PSPath/PSDrive/PSProvider` (449KB שלא נפרס), ופלט ב-codepage של הקונסולה עושה
   **best-fit** ל-em-dash → מרכאה ASCII *בתוך* מחרוזת JSON. פתרון: `[string]$_` + סינון ל-ASCII +
   `[Console]::OutputEncoding = UTF8`.
2. **`~` הוא לא הבית האמיתי כאן** — בסביבת Antigravity `expanduser("~")` מחזיר פרופיל-ארגז, ולכן
   מפתח ה-ssh "לא קיים" וכל בדיקה מרוחקת נכשלה. פתרון: `FOLDERID_Profile`.
3. **אל תנפישו `pos` של ווידג'ט שמנוהל ע"י layout** — ה-layout ממקם אותו מחדש תוך כדי, וזה גרם
   לטקסט חופף ולכרטיס שנעלם. אנימציית ה"עלייה" נעשית דרך ה-margin העליון של ה-layout, וה-fade דרך
   `QGraphicsOpacityEffect`.
4. **סרגל מכווץ חייב אייקונים** — 72px עם כפתורי טקסט בלבד הוא פשוט ריק.
5. **אחוז מעוגל שקרן** — `f"{202611/202702*100:.1f}%"` נותן **100.0%** בזמן ש-91 שורות עוד
   בתור. `fmt_pct()` מעגל כלפי **מטה** ושומר את 100% אך ורק ל-remaining=0. אחוז שמוצג לאדם הוא
   טענה על מצב — אסור שהעיגול יחזק אותה מעבר לנתונים.
6. **צילום חלון ל-QA**: `ImageGrab` מצלם מלבן-מסך (וצילם לי את ה-IDE); `PrintWindow(hwnd, hdc,
   PW_RENDERFULLCONTENT)` מצלם את החלון עצמו. וב-onefile של PyInstaller החלון שייך ל-**תהליך הבן**.
