## ⚠️ שמירת תגיות markup — קריטי (qa_merge דוחה תיקון שמשנה תגיות! — כלב שמירה #2)

הרבה שורות מכילות תגיות `<Rich .../>`, `<kiroshi .../>`, placeholders `{VALUE,...}`,
פורמטים `%d` `%%`, ותווי `&rlm;` `&#xA;`. **אי-אפשר לשנות, לזוז, להוסיף, למחוק אותם** —
`qa_merge.py` בודק שהתגיות זהות 100% למקור ודוחה כל שינוי עם `TAG/PLACEHOLDER MISMATCH`.

**כלל ברזל: רק הטקסט העברי בין/סביב התגיות משתנה. התגיות עצמן מועתקות מילה-במילה.**

**שורה עם `<Rich color="...">`:**
```
he: "זמן <Rich color="#4FC1F0">הקפאה</> שניות"
en: "Freeze <Rich color="#4FC1F0">Duration</> Seconds"
תיקון נכון: "משך <Rich color="#4FC1F0">הקפאה</> בשניות"   ← התג הועתק בדיוק, רק העברית מסביב השתנתה
תיקון שגוי: "משך הקפאה בשניות"                              ← מחקת את התג! REJECT
```
**שורה עם `{VALUE,...}`:**
```
he: "נזק: {RED}{VALUE,DAMAGE}{/}"  → תיקון: "נזק: {RED}{VALUE,DAMAGE}{/}"   (placeholder מילה-במילה)
```
**שורה עם `%d`:**
```
he: "כוח %d"  → תיקון: "עוצמה %d"   ← `%d` נשאר.   "עוצמה" בלבד = REJECT.
```
**שורה עם `<kiroshi l="..." o="...">`:**
```
he: "<kiroshi l="en" o="Wait.">רגע.</>"  → "<kiroshi l="en" o="Wait.">המתן.</>"   ← התג נשמר, רק העברית אחרי > משתנה
```
**שמירת `\n` (ירידת-שורה ספרותית):** אם ב-`he` יש `\n` (שני התווים `\` ואז `n`, לא ירידת-שורה אמיתית) —
העתק אותו **בדיוק ככה**. אל תהפוך אותו לירידת-שורה אמיתית — ככה גם המקור האנגלי כתוב, וזו רגרסיה.

**אם זיהית בעיה אבל אינך יכול לתקן בלי לשבור תגית → כתוב `"OK"`.** אל תנסה לתקן תגיות.
