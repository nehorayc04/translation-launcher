# GoWR — תרגום 591 מחרוזות שנשארו אנגלית מלאה לעברית

**רקע:** במוד העברי של God of War: Ragnarök נמצאו **591 מחרוזות** (דיאלוג, שורות משימה, תיאורי
פריטים/אויבים, UI) שהריצה המקורית **פספסה** — הן עדיין **אנגלית מלאה** ומוצגות לשחקן באנגלית.
המשימה: לתרגם את כולן לעברית טבעית. (402 אנגלית רגילה + ~189 שורות **נורדית-עתיקה** flavor.)

> **המקור הוא ה-`en` בלבד.** אל תחפש ערבית — ב-GoWR אותו id מצביע על שורה ערבית **שונה**, אז
> הערבית מטעה. תרגם את מה שכתוב ב-`en`.

## הלולאה (חזור עד "All done!")
```
python get_batch.py 40      # כותב current_batch.json = { id: {"en": <אנגלית>, "he": ""} }
# מלא את "he" בכל פריט = תרגום עברי של ה-"en"
python merge_batch.py       # מאמת + ממזג ל-done_translate.json; דוחה שורה לא-תקינה
```
כשמופיע "All done!" — סיימת. (591 שורות.)

## כללים נוקשים
1. **אנגלית רגילה → עברית טבעית וזורמת** (רגיסטר נורדי/דרמטי של המשחק).
2. **נורדית-עתיקה** (שורות עם `þ ð æ ø á í`, מילים כמו `at/er/munu/vengi/munn`, למשל
   `Hvat er at gerast?!`, `Eldingar vengi!`) — **תעתק לאותיות עבריות** (שמור את הצליל הזר,
   זו אווירה מכוונת), למשל `Bifröst vengi!` → `ביפרוסט וונגי!`. **אסור להשאיר אותיות לטיניות.**
3. **שמור מילה-במילה** (העתק, אל תשנה): קידומת `[[S:...]]` בתחילת השורה (אם יש), `\n` (אותו מספר),
   `[style=Highlight]`/`[/style]`, `[i]`/`[/i]`, `[HeavyAttackButton]` וכל `[...]`, `<...>`, `%d`.
4. **שמות → תעתיק עברי מקובל:** Kratos=קרייטוס, Atreus=אטראוס, Odin=אודין, Thor=ת'ור, Surtr=סורטר,
   Freya=פרייה, Mimir=מימיר, Sindri/Brok/Tyr/Bifröst=ביפרוסט/Asgard=אסגארד/Midgard=מידגארד.
5. **בלי ניקוד. בלי להשאיר מילים באנגלית/לטינית** (חוץ ממותגים: Sony/PlayStation/NVIDIA DLSS/
   AMD FSR/DualSense). המאמת דוחה שורה עם מילה לטינית שנשארה, טוקן שהשתנה, או מספר `\n` שונה.
6. אל תמציא/תשמיט תוכן. אל תיגע ב-`to_translate.json` — רק ב-`current_batch.json`.
