אתה סוכן עם היסטוריה ריקה. סוכנים קודמים תרגמו חלק. **אתה ממשיך מאיפה שעצרו ומסיים את הכל.** קרא את המסמך במלואו לפני שתתחיל.

## 🚀 זרימת העבודה — השתמש בסקריפט-העזר (אל תאלתר flow משלך!)

יש סקריפט עזר מוכן: `games/spiderman2/work/gemini_translate_helper.py`. **הוא פותר את הכאב של הסוכן הקודם** (escaping של מירכאות בתגיות `<ts="...">`). אתה **אף פעם לא מקליד תגיות תזמון** — הסקריפט ממיר אותן ל-marker בלי מירכאות (`@@TS1@@`) ומחזיר אותן לבד.

**הלולאה (חזור עליה עד "All done!"):**

1. **קבל באצ':**
   ```
   python "C:\Users\Nehoray_Cohen\Projects\Game translator\games\spiderman2\work\gemini_translate_helper.py" get 100
   ```
   זה כותב `games/spiderman2/work/gemini_temp_input.json` בפורמט `{ "KEY": "@@TS1@@English text" }`, ומדפיס כמה נשארו.

2. **תרגם:** ערוך את `gemini_temp_input.json` — החלף כל **ערך** (הטקסט האנגלי) בתרגום העברי שלו.
   - **שמור את ה-markers `@@TS1@@` / `@@TS2@@` בדיוק במקומם** (הם תגיות התזמון). **לעולם אל תקליד `<ts=...>` בעצמך.** דוגמה: `"@@TS1@@Stop with the webs already!"` → `"@@TS1@@חלאס עם הקורים האלה!"`.
   - הקפד על כל הכללים הנוקשים למטה. בגלל ה-markers, הערכים הם מחרוזות בלי מירכאות פנימיות → אין כאב escaping.

3. **שמור ואמת:**
   ```
   python "C:\Users\Nehoray_Cohen\Projects\Game translator\games\spiderman2\work\gemini_translate_helper.py" put
   ```
   הסקריפט **מאמת אוטומטית** כל שורה (תגיות תזמון, placeholders, `%%`, ניקוד, כתב-זר, `&rlm;`, שמות, נוכחות עברית) וממזג רק את התקינות ל-`sm2_subtitles_he.gemini.json`. אם משהו נפסל — הוא מדפיס בדיוק מה ולמה; **תקן רק את אלה ב-`gemini_temp_input.json` והרץ `put` שוב.**

4. חזור ל-1. סיימת כשהסקריפט מדפיס **"All done!"**.

**אל תיגע ידנית** ב-`sm2_subtitles_he.gemini.json`, ב-`subtitles_he.json`, או בקבצי `.bak_*` — הסקריפט מטפל במיזוג. אל תכתוב סקריפטים משלך לבניית dict-ים — זה מה שגרם לכאב לסוכן הקודם.

## 📐 כללים נוקשים לתרגום (הסקריפט אוכף אותם — הפרה = השורה נפסלת ותחזור)

1. **רק אותיות עברית + לטיניות.** אסור כל כתב אחר (ערבית/קירילית/יוונית/תאית/CJK/קוריאנית/דוונאגרי). **לעולם אל תשתמש בניקוד.**
2. **העתק במדויק, ללא שינוי, באותו מיקום:** ה-markers `@@TSn@@`; placeholders `[TOKEN_גדול]` ו-`{VALUE}`; format specs `%d %u %s %i %f %%` (**לעולם אל תכווץ `%%` ל-`%`**); תגיות `&rlm;` `&gt;` `&nbsp;` `<br>` `<span>` `</span>`.
3. **שמות נשארים באנגלית בדיוק** — דמויות: Spider-Man, Miles, Peter, MJ, Mary Jane, Harry, Norman, Venom, Anti-Venom, Carnage, Kraven, Sandman, Lizard, Electro, Mister Negative, Martin Li, Wraith, Yuri, Rio, Jeff, Symbiote, Scream, Taskmaster, Tombstone, Vulture. מקומות/מותגים: New York, Brooklyn, Queens, Manhattan, Harlem, F.E.A.S.T., Oscorp, Daily Bugle, ESU, NYPD, S.H.I.E.L.D.
4. **רמזי-קול בסוגריים** `[...]`: תרגם את המילה שבפנים, שמור את הסוגריים — `[laughing]`→`[צוחק]`, `[gasping]`→`[נאנח]`, `[grunting]`→`[נחירה]`, `[groaning]`→`[גניחה]`, `[sighing]`→`[אנחה]`, `[coughing]`→`[שיעול]`, `[screaming]`→`[צרחה]`, `[crying]`→`[בכי]`, `[panting]`→`[התנשפות]`. לכל אחר — מילה עברית קצרה.
5. **`&rlm;` בסוף:** ה-`get` מדפיס לכל ערך `(rlm=True/False)`. אם `rlm=True` → התרגום **חייב להסתיים בדיוק ב-**`&rlm;`. אם `rlm=False` → אל תוסיף `&rlm;`.
6. **מחרוזת שהיא רק markers/placeholders בלי מילים אמיתיות** → החזר אותה כמו שהיא.
7. **מגדר:** מפתחות שמסתיימים ב-`_MILES`/`_PETER` = ביוגרפיות בגוף ראשון של Miles/Peter (זכרים) → גוף ראשון זכר ("אני זוכר", "צריך", "יכול"). שאר הדיאלוג — ברירת מחדל זכר, אלא אם הדובר/ת נקבה ברורה (MJ, Rio, Yuri/Wraith, Hailey, Felicia/Black Cat, Danika, Aunt May).
8. **אסור אותיות לטיניות עם דיאקריטים** (ł, ć, ś, ó, é, à, ü, ä) אלא אם הן קיימות במקור.
9. עברית **מדוברת, ישראלית, אנרגטית** (טון משחק אקשן, לא ספרותי). טבעי, לא מילה-במילה. (כיוון: כתוב עברית רגילה "לוגית" — אל תהפוך אותיות/מילים; הצינור מטפל ב-RTL לבד.)
