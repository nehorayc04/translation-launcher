# משימה: תרגום VirtualDJ 2026 לעברית (עידן חדש)

אתה מתרגם מקצועי לעברית של תוכנת הדיג'יי **VirtualDJ**. עבוד בתיקייה:
`games/virtualdj/agent_handoff/`

## הלולאה (חזור עליה עד "All done!")
1. `python get_batch.py 60`
   → כותב `current_batch.json` = `{key: {"en":..., "refs":{de,fr,es,it,ru,pt,nl,el,ja,zh,ar}, "he":""}}`
2. מלא את השדה `"he"` של כל מפתח בעברית (ראה כללים למטה). **אל תיגע ב-`en`/`refs`/במפתחות.**
3. `python merge_batch.py`  → מאמת + ממזג ל-`hebrew.json`, מדפיס כמה נדחו.
4. אם נדחו שורות — הן יחזרו ב-batch הבא; תקן ותמשיך. חזור ל-1.

## עידן חדש — תרגם לפי המשמעות, לא מילולית
`en` = טקסט המקור לתרגום. `refs` = אותה שורה שכבר תורגמה לשפות אחרות — **השתמש בהן רק כדי להבין
משמעות, הקשר, מגדר ומספר** (הערבית לבדה לפעמים שגויה; הצלב מול de/fr/es/it/ru). תרגם את המשמעות
של `en` לעברית תקינה, טבעית ותמציתית, במשלב תוכנה (כמו Windows בעברית).

## כללים נוקשים
- **עברית לוגית רגילה** (אל תהפוך אותיות). **בלי ניקוד. בלי כתב זר** (ערבית/סיריליק/CJK/יוונית).
- **שמור כל טוקן מילה-במילה, אותו מספר:** `%i %s %d %% %2F %c` וכל `%<אות>`, וסמני קישור `[[...]]`.
  אם ב-`en` יש `%s`/`%d` — חייב להופיע גם בעברית באותה כמות.
- **שמות מותגים/מוצרים ונוסחאות נשארים לטיניים:** VirtualDJ, ASIO, MIDI, CDJ, BPM, FX, EQ, LFO,
  HPF, LPF, DRM, USB, iTunes, Serato, RekordBox, Traktor, Deezer, TIDAL, SoundCloud, Shazam,
  Spotify, Beatport, virtualdj.com, `%AppData%`, `.m3u`, ogg, mp3, Chrome.
- **שמות פקודות/פרמטרים של VDJScript נשארים באנגלית:** למשל `mix_now`, `sampler_bank`, `beatjump`,
  `pitch_lock`, `auto_bpm_transition`, `AskTheDJ`, `MyLists`, וכל דוגמת קוד במרכאות.
- מונחון: Deck=דק, Loop=לולאה, Sampler=דוגם, Crossfader=קרוספיידר, Cue=קיו, Gain=גיין,
  Pitch=פיץ', Stems=סטמס, Beatgrid=רשת מקצבים, Skin=עיצוב, Broadcast=שידור, Karaoke=קריוקי,
  Automix=אוטומיקס, Track=טראק.
- שורה שהיא רק שם/קוד (בלי מילים אמיתיות) — מותר להשאיר כפי שהיא באנגלית.

## אנטי-רמאות (חובה)
- **אסור** להעתיק את האנגלית כתרגום לשורת פרוזה (שורה עם ≥2 מילים אמיתיות). ה-merge ידחה זאת.
- **אסור** להשמיט/להוסיף טוקן `%`. **אל תכתוב סקריפט שממלא אוטומטית** — תרגם כל שורה לגופה.
- אל תסמן "סיימתי" עד ש-`get_batch.py 60` מדפיס בעצמו **"All done!"**.
