# המאגר העצמאי — שרת מחשוב-קהילתי מתארח עצמית

תשתית מקבילה ל-Turso + Cloudflare Worker, על **מחשב ה-Home Assistant** (`10.0.0.20`).
נבנתה מבלי לגעת בצי הפעיל, באפליקציות או ב-Turso.

---

## למה

| | Turso + Worker (היום) | המאגר העצמאי |
|---|---|---|
| אחסון | 5GB, מכסת כתיבות | **דיסק מקומי — אין מכסה** |
| תקרת מכשירים | ~1,000 (מכסת כתיבות) | **נמדד: 174 בקשות/שנייה** ≈ אלפים |
| בעלות על הנתונים | אצל ספק חיצוני | **על המחשב שלך** |
| פעימת חיים | 5 דק' (כדי לחסוך כתיבות) | ניתן להוריד ל-60 שנ' בלי עלות |
| זמינות | ~99.99% | תלוי בחשמל/בזק ביתי (יש סוללה) |

## מה מותקן על `10.0.0.20`

```
/opt/cc-pool/
  cc_server.py     השרת (פייתון סטנדרטי בלבד, ללא התקנות)
  cc.env           סודות + הגדרות (הרשאות 600)
  cc_pool.db       מסד הנתונים (SQLite במצב WAL)
  sqlexec.py       הרצת SQL מ-stdin (עוקף מלכודות ציטוט)
  backup.py        גיבוי מקוון + אימות שלמות + דחיסה
  watchdog.sh      בדיקת בריאות ואתחול בתקיעה
  backups/         14 גיבויים אחרונים, .db.gz

שירותים:
  cc-pool.service           רץ תמיד, אתחול אוטומטי
  cc-pool-backup.timer      כל יום ב-04:30
  cc-pool-watchdog.timer    כל 5 דקות
  caddy                     מותקן, מושבת עד לפתיחת הפורטים
```

**החוזה זהה לחלוטין ל-Worker** (`/cc/enroll`, `claim`, `renew`, `submit`,
`release`, `stats`, `detail`, `config`, `block`, `unblock`) — האפליקציה והזרמים
צריכים **רק שינוי כתובת**, אפס שינויי קוד.

## 🔴 מלכודת שנתפסה בסריקה — חובה לדעת לפני המעבר

**`PYTHONPATH` אינו גובר על ספריית הסקריפט עצמו.** ההרצה הזו נראית כאילו היא
מכוונת למאגר העצמאי — והיא מכוונת ל**ייצור**:

```bash
cd control_plane/turso && PYTHONPATH=../selfhost python cc_seed.py corpus.json   # ❌ מסוכן
```

פייתון שם את ספריית הסקריפט ב-`sys.path[0]`, לפני כל מה שב-`PYTHONPATH`, אז
`import turso_client` בתוך `turso/cc_seed.py` תמיד נפתר ל-`turso/turso_client.py`.
בסריקה זה שלח **500 שורות בדיקה למסד הייצור החי**, ליד הקורפוס האמיתי — והזורע
דיווח "הצלחה", כי שני היעדים תקינים ושתי התשובות נראות נכון.

*(נוקה מיד; אף מכשיר לא הספיק לתפוס מהן — כולן נשארו `open`.)*

**תמיד להשתמש במריץ:**
```bash
cd control_plane/selfhost && python run.py cc_seed.py corpus.json --game X   # ✅
```
הוא מדפיס לאיזה יעד הוא מכוון, ו**מסרב לרוץ** אם נטען הצד השגוי.

## שתי פעולות שנשארו — שלך, לא שלי

השרת מאזין כרגע **רק ברשת המקומית**. כדי לחשוף אותו:

**1. רשומת DNS** — ב-Cloudflare, הוסף:
```
Type: A    Name: cc    Content: 85.130.231.111
Proxy: מומלץ מופעל (ענן כתום) — מסתיר את ה-IP הביתי ומוסיף הגנה
```

**2. הפניית פורטים** — באפליקציית בזק, "ניהול פורטים":
```
443 TCP  ->  10.0.0.20
80  TCP  ->  10.0.0.20     (רק להנפקת התעודה; אפשר לסגור אחר כך)
```

ואז, כשזה מוכן:
```bash
ssh root@10.0.0.20 "systemctl enable --now caddy"
curl https://cc.hebrew-translation-hub.com/health     # מבחוץ, מרשת סלולרית
```

> ⚠️ בדיקה מבחוץ **חייבת** להיות מרשת סלולרית — הנתב אינו תומך ב-NAT loopback,
> אז בדיקה מהבית תיכשל גם כשהכול תקין.

## אחרי החשיפה — סדר המעבר (הדרגתי, בלי להפיל כלום)

1. **טעינת משחק למאגר החדש** — `cc_seed.py` עם כתובת השרת החדשה.
2. **מכשיר ניסיון אחד** — לשנות `ccBase` באפליקציה ולוודא משיכה/שליחה.
3. **המרת הזרמים** — כל מכונה מריצה את לקוח הדסקטופ במקום קובץ מנה קבוע.
4. **ביטול החלוקה הפיזית** — `reslice_equal.py` / `push_shards_restart.py` הופכים
   למיותרים.
5. **ניתוק Turso** — רק אחרי יממה יציבה. להשאיר כגיבוי.

**המלצה:** להשאיר את ה-Worker כמצביע דק לשרת הביתי — אז כתובת האפליקציה
**לעולם לא תשתנה שוב**, גם אם תחליף מחשב או תחזור ל-Turso.

## פקודות תפעול

```bash
# מצב
ssh root@10.0.0.20 "systemctl status cc-pool --no-pager"
curl -s -H "x-cc-secret: $CC_SECRET" http://10.0.0.20:8787/cc/stats

# מי עובד על מה (דורש סוד מנהל)
curl -s -H "x-cc-secret: $CC_ADMIN_SECRET" http://10.0.0.20:8787/cc/detail

# שינוי תדירות חי — בלי בנייה מחדש של האפליקציה
curl -s -X POST -H "x-cc-secret: $CC_ADMIN_SECRET" -H "Content-Type: application/json" \
     -d '{"set":{"heartbeat_seconds":600}}' http://10.0.0.20:8787/cc/config

# גיבוי ידני
ssh root@10.0.0.20 "python3 /opt/cc-pool/backup.py"

# הרצת מערך הבדיקות
CC_BASE=http://10.0.0.20:8787/cc CC_SECRET=... CC_ADMIN_SECRET=... python cc_smoke_selfhost.py
CC_BASE=http://10.0.0.20:8787/cc CC_SECRET=... python cc_load_selfhost.py
```

הסודות נמצאים ב-`/opt/cc-pool/cc.env` על השרת. סוד המכשיר **זהה** לזה שבאפליקציה
1.0.1, כדי שהמעבר יהיה שינוי כתובת בלבד.
