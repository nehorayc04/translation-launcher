# משימה: השלמת תרגום — Marvel's Spider-Man 2 (עברית)

אתה מתרגם עצמאי (אין לך היסטוריית שיחה קודמת). התיקייה הזו מכילה **102 רשומות** משני
סוגים שנמצאו במחסן הטקסט של המשחק:

- **90 רשומות `dialogue_full`** — טקסטים ביוגרפיים/יומן (בעיקר `BIO_*`) שתורגמו בעבר
  אבל **נקטעו** באמצע — לפעמים אחרי משפט אחד בלבד, כשה-EN המקורי ארוך בהרבה. צריך
  **תרגום מלא מחדש מה-EN**, לא "השלמה" של החתיכה הקיימת (זה ימנע חוסר עקביות בסגנון
  בנקודת התפר).
- **12 רשומות `subtitle_segment`** — כתוביות עם כמה קטעי `<ts="...">`; **קטע אחד**
  נשאר לגמרי באנגלית בזמן שהשכנים שלו כבר מתורגמים. צריך למלא **רק את הקטע החסר**,
  ולהשאיר את שאר הקטעים **בדיוק כפי שהם** (אות באות, כולל `&rlm;`).

## כללי ברזל (חובה, ללא יוצא מן הכלל)

1. **שמור כל טוקן טכני בדיוק כפי שהוא, במקום המדויק שלו:**
   - `<ts="123;456">` — תגי תזמון כתוביות (הסדר ביניהם קובע את סדר השורות על המסך —
     **לעולם אל תחליף את הסדר שלהם**).
   - `<br>` / `<br/>` — מעברי שורה בטקסט ביוגרפי.
   - `&rlm;` — עוגן כיווניות RTL, כמעט תמיד בסוף המשפט/הקטע. **תמיד תשאיר בדיוק במקום
     שבו הוא מופיע ב-EN** (בסוף השורה/הקטע המקביל).
   - `[PETE ICON]` / `[MILES ICON]` — טוקן שמזהה את דיוקן הדובר, **לא מתרגמים** את
     המילה בסוגריים.
   - `[ALLCAPS_TOKEN]` — כל טוקן שכולו אותיות גדולות/מספרים/קו תחתון בסוגריים
     מרובעים (כמו `[CUT]`, `[RELOAD]`) — **לא מתרגמים**, נשאר בדיוק כמו שהוא.
   - `{VALUE}` — פלייסהולדר, לא מתרגמים.
   - `%d` / `%s` וכו' — פורמט printf, לא מתרגמים.
2. **שמות דמויות** נשארים תמיד באנגלית לטינית **בתוך פרוזה** (V, Pete, Miles, Harry,
   MJ...) — אבל אם מדובר בברירת-מחדל שכבר קיימת ב-`current_he` (למשל "פיט"/"מיילס"),
   **תשמור על העקביות עם מה שכבר קיים באותה רשומה או בקורפוס** — אל תשנה שם שכבר
   מתורגם בעקביות למשהו אחר.
3. **בלי ניקוד. בלי שום שפה זרה** (לא ערבית/רוסית/יוונית/תאילנדית/הינדי/סינית/יפנית/
   קוריאנית) — עברית + אנגלית (לטינית) בלבד, ורק במקומות שבהם אנגלית לגיטימית (שמות/
   מותגים/קודים כפי שתואר למעלה).
4. **סגנון** — Spider-Man 2 הוא משחק ניו-יורקי, דיבורי, לפעמים הומוריסטי. השתמש בעברית
   טבעית, לא ספרותית-קפואה. שמור על מרשם הדובר (מייל/פיטר מדברים בבגרות רגישה; מיילס
   צעיר וקליל יותר; קרייבן פורמלי-איום).
5. **`subtitle_segment`**: אתה מקבל את **הערך המלא הנוכחי** (`current_he`), עם הקטע
   החסר עדיין באנגלית בתוכו, ואת ה-EN **המלא** של כל השורה (למקד את הבנת ההקשר). אתה
   **מחזיר את הערך המלא** (כל הקטעים, לא רק את מה שתיקנת) — פשוט תרגם את החלק
   שבאנגלית והשאר תשאיר **אות-באות זהה** למה שהיה ב-`current_he`.

## איך זה עובד (לולאה אוטונומית — בצע בעצמך, בלי לעצור ולשאול)

```
python get_batch.py
```
כותב `current_batch.json` (עד 30 רשומות: `{id: {kind, en, current_he}}`). אם הפלט
"All done!" — סיימת, אין עוד מה לעשות, תדווח שסיימת.

עבור על `current_batch.json`, ותרגם כל רשומה. כתוב **קובץ חדש** `trans_batch.json`
בתיקייה הזו, בפורמט `{id: "הערך המתורגם המלא"}` — **מפתח = אותו id בדיוק, ערך = מחרוזת
עברית מלאה** (לא רשימה, לא dict — string רגיל).

לדוגמה, אם `current_batch.json` מכיל:
```json
{
  "BIO_EXAMPLE_01": {"kind": "dialogue_full", "en": "Full English text here.<br><br>More text.", "current_he": "טקסט חלקי בלבד&rlm;"},
  "SUB_EXAMPLE_02": {"kind": "subtitle_segment", "en": "<ts=\"0;100\">Hebrew part.<ts=\"100;200\">Missing English part.", "current_he": "<ts=\"0;100\">חלק בעברית.&rlm; <ts=\"100;200\">Missing English part."}
}
```
`trans_batch.json` צריך להיות:
```json
{
  "BIO_EXAMPLE_01": "טקסט מלא בעברית.&rlm;<br><br>עוד טקסט.&rlm;",
  "SUB_EXAMPLE_02": "<ts=\"0;100\">חלק בעברית.&rlm; <ts=\"100;200\">החלק החסר תורגם עכשיו.&rlm;"
}
```
(שים לב: ב-`SUB_EXAMPLE_02` הקטע הראשון `<ts="0;100">חלק בעברית.&rlm;` **נשאר בדיוק
זהה** למה שהיה ב-`current_he` — רק הקטע השני תורגם.)

ואז הרץ:
```
python merge_batch.py
```
זה מאמת (טוקנים/`<ts>`/ניקוד/שפה זרה) ומאחד רק רשומות תקינות ל-`hebrew_fixes.json`.
כל רשומה שנכשלת מודפסת עם הסיבה — **תקן רק אותה** ב-`trans_batch.json`, הרץ שוב
`merge_batch.py`.

**חזור על `get_batch.py` → תרגם → `merge_batch.py`** עד ש-`get_batch.py` מדפיס
"All done!". אל תעצור באמצע ותשאל — זו לולאה עצמאית.

## קובץ `skip.json` (אופציונלי)

אם נתקלת ברשומה שבאמת אי אפשר לתרגם (למשל מזהה טכני שגוי או תוכן שבור לגמרי שאין לו
מקבילה הגיונית) — אפשר להוסיף את ה-id לרשימה ב-`skip.json` (מערך JSON של מחרוזות) כדי
שהלולאה תדלג עליו ותגיע ל"All done!" גם אם יש שאריות בעייתיות אמיתיות. תשתמש בזה
בזהירות — רוב הרשומות כאן **כן ניתנות לתרגום מלא**, זו הסיבה שהן הגיעו לכאן.
