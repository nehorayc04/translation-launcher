# GoWR — השלמת 30 מחרוזות שנשארו חצי-אנגלית לעברית

**רקע:** במוד העברי של God of War: Ragnarök יש **30 מחרוזות** (תיאורי רמזי-שמע, הודעות
UI, שורות דיאלוג) שתורגמו רק בחלקן — חלקן עברית וחלקן **נשאר באנגלית**. המשימה: **להשלים
את החלק האנגלי לעברית**, כך שכל המחרוזת עברית שוטפת ואחידה.

## הלולאה (חזור עד "All done!")
```
python get_batch.py 30      # כותב current_batch.json = { id: {he_partial, en, ar, "he":""} }
# מלא את "he" בכל פריט = המחרוזת המלאה בעברית (השלם/תרגם את החלק האנגלי)
python merge_batch.py       # מאמת + ממזג ל-done_translate.json; דוחה שורה לא-תקינה
```
כשמופיע "All done!" — סיימת. (30 מחרוזות.)

## מה נתון לכל פריט
- `he_partial` — הטקסט הנוכחי (חלקו עברית, חלקו אנגלית). **זו נקודת ההתחלה — תקן/השלם אותו.**
- `en` — המקור האנגלי המלא (עזר משמעות).
- `ar` — הערבית הרשמית (עזר משמעות + מגדר: `أنتَ`=אתה, `أنتِ`=את).

## כללים נוקשים
1. **התוצאה = המחרוזת המלאה בעברית טבעית** — קח את `he_partial`, ותרגם לעברית כל מילה/משפט
   אנגלי שנשאר בו. שמור את החלקים שכבר עברית.
2. **שמור מילה-במילה** (אותו מספר, אותו כתיב — העתק, אל תשנה): כל `[...]` (כמו `[HeavyAttackButton]`,
   `[BlockButton]`, `[AxeRecallButton]`, `[CompanionAmmoButton]`), `[style=Highlight]`/`[/style]`,
   `[style=OrangeText]`, `<...>`, `%d`, `\n` (שבירות שורה).
3. **שמות מותגים נשארים באנגלית:** `Sony`, `PlayStation`, `Sony Interactive Entertainment`.
   מונחי-משחק כלליים תרגם (Audio Cues=רמזי שמע, Rage=זעם, Runic=רוני וכו').
4. **בלי ניקוד. בלי להשאיר מילים אנגליות** (חוץ ממותגים) — המאמת דוחה שורה שבה נשארו מילים
   אנגליות אמיתיות, שהטוקנים השתנו, או שמספר ה-`\n` השתנה.
5. אל תמציא/תשמיט תוכן. אל תיגע ב-`to_translate.json` — רק ב-`current_batch.json`.
