# חבילת לפטופ — זרם תרגום שני ל-CP2077 (מפתח שני, IP אחר)

NIM של NVIDIA חוסם **לפי כתובת IP** — כל המפתחות מאותו מחשב חולקים את אותה מכסה.
לפטופ ברשת אחרת + מפתח שני = **מכסה עצמאית ≈ פי-2 מהירות**. הלפטופ מתרגם, מייצר
`out.json` בדיוק בפורמט שהמחשב הראשי בונק, ואתה מעתיק את הקובץ חזרה כל כמה שעות.

---

## מה בתיקייה
- `laptop_nim.py` — המתרגם העצמאי (stdlib בלבד, בלי pip).
- `corpus.json` — 50,000 השורות **הכי ארוכות** (מעובד ארוכים-קודם, כדי לא להתנגש עם
  המחשב הראשי שעושה קצרים-קודם).
- `key.txt.example` — תבנית למפתח.

## הפעלה על הלפטופ (5 דקות)
1. התקן **Python 3.10+** מ-python.org (סמן "Add Python to PATH"). אין צורך ב-pip.
2. שים את **המפתח השני** ליד הסקריפט — צור קובץ בשם `key.txt` שמכיל **רק** את המפתח:
   ```
   nvapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   (או `set NVIDIA_API_KEY=nvapi-...` ב-CMD לפני ההרצה.)
3. פתח CMD בתיקייה הזו והרץ:
   ```
   python laptop_nim.py
   ```
4. השאר פתוח. הוא מתרגם בלולאה, כותב `out.json` אחרי כל באץ', ומתחדש מעצמו אם עוצרים
   ומריצים מחדש (מדלג על מה שכבר תורגם).

## איך התרגום חוזר למחשב הראשי (זה מה שבונק אותו)
כל כמה שעות **העתק את `out.json` מהלפטופ** אל המחשב הראשי, אל הנתיב:
```
...\games\cyberpunk2077\agent_handoff_qa\retrans_agent_laptop\retrans_corrections.json
```
(פשוט שכתב את הקובץ הקיים שם.) ה-watchdog במחשב הראשי אוסף אותו אוטומטית תוך ~4 דקות,
מאמת כל שורה שוב (ולידציה מלאה), ובונק ל-checkpoint. אפשר להעתיק בכל דרך: USB, מייל
לעצמך, WhatsApp Web, או תיקיית OneDrive/Google-Drive משותפת.

> 💡 **הכי נוח:** אם תשמור את `out.json` בתיקיית OneDrive על הלפטופ, ותגיד לי את
> הנתיב, אחבר את המחשב הראשי לקרוא ממנה ישירות — ואז אין צורך להעתיק ידנית בכלל.

## חשוב
- **אל תשים את המפתח בצ'אט** — רק בקובץ `key.txt` על הלפטופ.
- `out.json` הוא מצטבר (snapshot מלא) — כל העתקה פשוט מעדכנת; בטוח לחלוטין, אין כפילויות
  (ה-watchdog מנפה מול מה שכבר בונק).
- הלפטופ עובד על השורות **הארוכות** והמחשב הראשי על הקצרות → כמעט אפס חפיפה ל-30+ שעות.
- אפשר לעצור ולהריץ שוב מתי שרוצים — לא מאבד כלום.
