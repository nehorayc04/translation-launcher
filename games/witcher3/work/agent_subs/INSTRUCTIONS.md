# משימה — תרגום כתוביות סרטוני הפתיחה של The Witcher 3 לעברית

אתה מתרגם 151 שורות כתוביות של **סרטוני ה-motion-comic** של המשחק The Witcher 3:
סרטון ה-**recap** שרץ בפתיחת המשחק (קריינות אפית — הקיסר אמהיר, פלישת נילפגארד) +
סצנות ה-**storybook**. רגיסטר: **ספרותי, אפי, גבוה** — כמו פרולוג/אגדה שמסופרת בקול.

## קבצי עבודה (בתיקייה הזו)
- `to_translate.json` — כל 151 השורות: `{key: {en, ar, ru, pl, es, it, fr, de}}`
- `get_batch.py` — כותב את הבאץ' הבא ל-`current_batch.json`
- `merge_batch.py` — מאמת וממזג את הבאץ' ל-`hebrew.json` (שער אנטי-רמייה)
- `hebrew.json` — הפלט המצטבר (מתחיל ריק)

## הלולאה (חזור עד "All done!")
```
python get_batch.py 30        # כותב 30 שורות ל-current_batch.json (שדה "he" ריק בכל אחת)
# ← מלא את "he" של כל שורה בעברית (ראה כללים למטה)
python merge_batch.py         # מאמת + ממזג ל-hebrew.json, מדפיס כמה נשארו
```
כשמופיע `All done!` — סיימת. אל תיגע בשום קובץ אחר.

## שיטת "עידן חדש" — השפות הן ה-oracle שלך, השתמש בכולן
- **משמעות:** האנגלית (`en`) היא המקור. כשמשפט דו-משמעי — אמת מול `ru/es/it/fr/de/pl`.
  (אם אין `en`, יש `ar_primary` — תרגם ממנו.)
- **מגדר ומספר (עברית דורשת מה שאנגלית מסתירה):** קבע את מגדר/מספר הנמען/הנושא לפי
  הצלבת השפות המגדריות:
  - **ערבית** (`ar`): أنتَ=אתה · أنتِ=את · أنتم=אתם/אתן.
  - **רוסית/פולנית** (`ru`/`pl`): עבר -л/-ла → מגדר הדובר.
  - **ספרדית/איטלקית/צרפתית** (`es`/`it`/`fr`): -o/-a → מגדר המושא/התואר.
  - קח **קונצנזוס של ≥2 שפות**. רבים ("אתם") **רק** אם הערבית ברבים (vous/voi/usted עלולים
    להיות יחיד מנומס — מלכודת).
  - הקריינות פונה ל"בני הצפון" (**זכר רבים**), בַּרד שמספר סיפור, וכו' — התאם.

## כללים נוקשים
1. **עברית בלבד** (שמות פרטיים/מונחים לועזיים מותר בלטינית). **בלי ניקוד.** בלי ערבית/קירילית/סינית/אחר.
2. **שמור תגיות בדיוק** כמו באנגלית, אותו מספר ואותו מקום: `<i>...</i>`, `<br>`, `{...}`, `%d`, ‎`&entity;`.
3. תרגום **נאמן ומלא** — בלי לקצר, בלי להוסיף.
4. **עברית לוגית** (סדר קריאה טבעי). אל תהפוך אותיות/מילים — הבנייה עושה RTL/visual לבד.
5. **שמות קנוניים** (חובה, אחיד):
   Geralt=גרלט · Emhyr=אמהיר · Ciri=סירי · Yennefer=יניפר · Triss=טריס · Vesemir=ויסימיר ·
   Dandelion=דנדליון · Zoltan=זולטן · Nilfgaard=נילפגארד · Nilfgaardian=נילפגארדי ·
   Novigrad=נוביגרד · Temeria=טמריה · Redania=רדניה · Cintra=סינטרה · Velen=וילן ·
   Skellige=סקליגה · Ard Skellig=ארד סקילג · Kaer Morhen=קאר מורן · Kaer Trolde=קאר טרולד ·
   White Frost=הכפור הלבן · Wild Hunt=הצייד הפראי · Conjunction of the Spheres=מפגש הספירות ·

## חשוב
- אל תסמוך על "סיימתי" של עצמך — `merge_batch.py` דוחה שורות פגומות (טוקן חסר/סקריפט זר/העתק אנגלית)
  והן חוזרות לתור. הרץ שוב `get_batch.py` עד שבאמת `All done!`.
- אל תריץ שום סקריפט אחר, אל תיגע בקבצי המשחק, אל תמחק תוכן קיים — רק מלא `he` ומזג.
