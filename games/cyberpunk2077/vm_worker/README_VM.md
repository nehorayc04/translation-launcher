# חבילת VM — זרם תרגום שלישי ל-CP2077 (מפתח שלישי, IP שונה דרך Avast SecureLine)

NIM של NVIDIA חוסם **לפי IP חיצוני**. VM רגיל (NAT/bridged) יוצא דרך אותו IP של המחשב
המארח → **אין רווח**. ה-IP השונה מגיע **רק אם בתוך ה-VM רץ Avast SecureLine המחובר
למיקום אחר** מזה של המארח. אז ה-VM יוצא ב-IP חדש → מכסת NIM עצמאית → זרם שלישי.

> 💡 המתרגם הוא **לקוח ענן** — כל החישוב רץ על שרתי NVIDIA, לא מקומית. הוא כמעט לא צורך
> CPU/RAM. לכן VM קטן (2GB RAM, 2 vCPU) מספיק בשפע ולא מעמיס על המחשב.

הקורפוס כאן = **42,438 שורות קצרות, נפרדות לגמרי** מהלפטופ. ה-VM עובד longest-first
והמחשב הראשי shortest-first → מתכנסים מהקצוות ומחלקים את העבודה (dedup לכל חפיפה).

## מה בתיקייה
- `vm_nim.py` — המתרגם (stdlib בלבד, בלי pip).
- `corpus.json` — 42,438 השורות שה-VM מתרגם.
- `key.txt.example` — תבנית למפתח.

## הקמה (פעם אחת)

### 1. צור VM של Windows
- התקן **VirtualBox** (חינם) → צור VM עם **Windows 10/11** (ISO רשמי; אפשר בלי הפעלה —
  סימן-מים בלבד, VPN+Python עובדים מצוין). 2 vCPU, 2-4GB RAM, 40GB דיסק.
- אחרי ההתקנה: Devices → Insert Guest Additions CD → התקן (נדרש לתיקייה משותפת בשלב 5).
- (אלטרנטיבה מהירה אך פחות יציבה: **Windows Sandbox** המובנה ב-Win11 Pro — נפתח בשניות
  בלי התקנת OS, אבל **נמחק בסגירה** ולא כל VPN עובד בו. ל-24 שעות עדיף VirtualBox.)

### 2. Avast SecureLine בתוך ה-VM — זה הלב
- התקן Avast SecureLine **בתוך ה-VM** והתחבר ל-**מדינה שונה** מזו של המארח.
- ⚠️ **חובה מיקום שונה** — אם תתחבר לאותו מיקום כמו ה-VPN של המארח, אולי תקבל אותו
  IP/subnet ו-NIM עדיין יחסום ביחד.
- בדוק כמה חיבורים בו-זמנית הרישיון מרשה (מארח + VM = חיבור אחד נוסף).

### 3. ✅ אמת שה-IP באמת שונה (קריטי — בלי זה אין טעם)
בתוך ה-VM, פתח PowerShell והרץ:
```powershell
Invoke-RestMethod https://api.ipify.org
```
המספר **חייב להיות שונה** גם מ-`169.150.235.105` (מחשב) וגם מ-`169.150.235.122` (לפטופ).
אם זהה לאחד מהם → החלף מדינה ב-Avast עד שהוא שונה.

### 4. Python
- התקן **Python 3.10+** מ-python.org בתוך ה-VM (סמן "Add Python to PATH"). אין צורך ב-pip.

### 5. תיקייה משותפת (כדי שהפלט יחזור אליי אוטומטית)
- **במארח:** צור תיקייה `C:\cp2077_vm_out`.
- ב-VirtualBox: Devices → Shared Folders → הוסף את `C:\cp2077_vm_out`, סמן **Auto-mount**
  + **Make Permanent**. היא תופיע ב-VM (בד"כ כ-`\\VBOXSVR\cp2077_vm_out` או כונן רשת).
- **חלץ את התיקייה `vm_worker` הזו לתוך התיקייה המשותפת בתוך ה-VM**, כך ש-`out.json`
  ייכתב ישירות לתיקייה המשותפת → אני קורא אותו מהמארח בלי צעד ידני.

### 6. הפעלה
- שים את **המפתח השלישי** ליד `vm_nim.py` — צור קובץ `key.txt` שמכיל **רק** את המפתח
  (`nvapi-...`). (או `set NVIDIA_API_KEY=nvapi-...` ב-CMD לפני ההרצה.)
- פתח CMD בתיקייה והרץ:
  ```
  python vm_nim.py
  ```
- הוא מתרגם בלולאה, כותב `out.json` אחרי כל באץ', ומתחדש מעצמו אם עוצרים ומריצים מחדש.

## איך הפלט חוזר למחשב הראשי
אם הכל בתיקייה המשותפת — `out.json` מופיע ב-`C:\cp2077_vm_out\out.json` במארח, **ואני
מושך אותו אוטומטית כל שעה** אל צינור הבנקינג. אין צורך להעתיק ידנית.

(fallback ידני: כל כמה שעות העתק את `out.json` מה-VM אל `C:\cp2077_vm_out` במארח.)

## חשוב
- **אל תשים את המפתח בצ'אט** — רק בקובץ `key.txt` בתוך ה-VM.
- `out.json` מצטבר (snapshot מלא) — בטוח, אין כפילויות (ה-watchdog מנפה מול מה שכבר בונק).
- אפשר לעצור ולהריץ שוב מתי שרוצים — לא מאבד כלום.
- כשתסיים לבדוק שה-VM רץ ומייצר — תגיד לי את הנתיב שבו `out.json` מופיע במארח, ואוסיף
  אותו למחזור המשיכה השעתי (זרם `retrans_agent_vm`).
