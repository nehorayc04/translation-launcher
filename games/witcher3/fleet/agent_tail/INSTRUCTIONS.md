## איך למלא כל שורה

לכל מפתח ב-`current_batch.json` יש `{"en": ..., "ar": ...}`:
- **`en`** = המשמעות באנגלית — **זה מה שאתה מתרגם** לעברית.
- **`ar`** = אותו משפט בערבית — **רק כרמז מגדר/מספר** (ערבית מסמנת מה שאנגלית משמיטה: أنتَ=אתה / أنتِ=את / أنتم=אתם, נקבה ـة→...ה, רבים). **אל תתרגם מהערבית ואל תעתיק מילים ערביות** — התאם רק את המגדר/מספר בעברית למה שהערבית מראה.

מלא את התרגום **כערך פשוט** (מחרוזת) או תוסיף שדה `"he"` לאובייקט — שניהם מתקבלים:
```json
{ "1209955": "מבין המעלות, החוכמה היא ..." }
```

## כללים נוקשים (merge_batch.py דוחה שורה שמפרה אותם — היא תחזור בסבב הבא)

1. **עברית תקינה בלבד** — בלי ניקוד, בלי אותיות ערביות/קיריליות/סיניות/וכו'.
2. **שמור כל תג/placeholder מילה-במילה מה-en:** `<br>`, `<font...>`, `</font>`, `{...}`, `%d`/`%s`, `&entities;`. אותו מספר, אותו סוג — אל תוסיף/תשמיט.
3. **שמות פרטיים** (Geralt, Dettlaff, Nilfgaard, Beauclair...) — תעתיק לעברית לפי הקנון של הזאב הלבן (גראלט, דטלף, נילפגארד, בוקלייר). אם שורה היא **רק שם/קוד** אפשר להשאיר כמו שהוא.
4. **טון** — עברית ספרותית, תואמת-תקופה (ימי-ביניים/פנטזיה), טבעית וזורמת. לא תרגום מילולי מכני.
5. **אל תמציא ואל תדלג** — תרגם את המשמעות המלאה של ה-`en`.
