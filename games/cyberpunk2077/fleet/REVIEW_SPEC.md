# CP2077 — מפרט הביקורת הרב-לשונית (עידן חדש)

זהו הרובריקה שהצי מבצע על כל שורה ב-`review_corpus/{onscreens,subtitles}.jsonl`.
המטרה: **אפס פספוס** של משמעות, מגדר, ושגיאות-לוואי — גם אם ייקח נצח.
Claude בונה+מאמת, **לא מתרגם** (`delegate-all-translation`).

---

## מבנה שורת-קורפוס (מה הסוכן רואה — בלי חיפושים נוספים)
```
id           מזהה (section:pk)
kind         onscreens | subtitles
en           מקור אנגלי
refs         { שפה: [femaleVariant, maleVariant] }  — כל 18 שפות המשחק
he           [femaleVariant, maleVariant]  — העברית הנוכחית
gendered     bool — האם שורה תלוית-מגדר (איחוד השפות שמפצלות fv!=mv)
split_langs  השפות שמפצלות מגדר על השורה + הצורות שלהן (ב-refs)
he_split     האם העברית עצמה מבחינה מגדר
det          דגלים דטרמיניסטיים (niqqud/foreign/brace_dropped/leading_latin/english_run)
```

---

## מודל 3 הסוגים (הגדרת המשתמש → מיפוי למנוע)
המנוע בוחר **fV** לשחקנית, **mV** לשחקן. `mV` ריק = "השתמש ב-fV".

- **סוג 1 — UI** (משימות/מטרות, פקודות, תיאורים, מגילות, שמות-חפצים): **ניטרלי.**
  fV==mV, זכר-כברירת-מחדל לפקודות, ניסוח לא-פונה לתיאורים. חריג: מטרת-משימה
  שפונה ל-V *כן* יכולה להיות מגודרת (fV נקבה / mV זכר).
- **סוג 2 — V מדבר** (kind=subtitles, הדובר הוא V):
  - על עצמו → לפי מגדר-השחקן (fV/mV), **אין רבים**.
  - על NPC/חפץ → מגדר-המושא **קבוע** (זהה ב-fV ו-mV): זכר/נקבה/רבים/חפץ.
- **סוג 3 — NPC מדבר**: על V (fV/mV לפי מגדר-שחקן) או על NPC (מגדר-מושא קבוע).

## אמינות התגים (נמדד — אל תתן בהם אמון עיוור)
- **אמין (הסוכן סומך):** `gendered`/`split_langs` (99.97% נקי — 16,341 פיצולים אמיתיים / 5 רעש),
  `axis` P2/P1, `imperative`, ו-`det` (דטרמיניסטי).
- **ראיה-בלבד (הסוכן מכריע, לא לסמוך):** `hom_candidate` (רובו מילים-נרדפות, לא פוליסמיה
  אמיתית — FENCE נדיר), `formality` FML/INF (משקף מוסכמת-משלב של שפה בודדת, לא משלב-השורה).
  קרא את כל ה-`refs` והכרע בעצמך.

## 🔑 ניואנס-מפתח: "שפה מפצלת" ≠ "עברית חייבת לפצל"
הערבית מגדרת אפילו **פקודות-UI** (`Interact`→تفاعلي/تفاعل). לכן `gendered=true` הוא
**טריגר לביקורת**, אבל התשובה תלויה ב**סוג**:
- **סוג-1 (UI: פקודה/תיאור/חפץ)** גם אם שפות מפצלות → עברית **ניטרלית זכר-ברירת-מחדל**
  (fV==mV: "פרק"/"פענח"), *לא* מפצלת. (חריג: מטרת-משימה שפונה ל-V.)
- **סוג-2/3 (דיאלוג: פנייה ל-V)** ושפות מפצלות → עברית **מפצלת** (fV="את..." / mV="אתה...").

## א. הכרעת מגדר (הציר שמבטיח וודאות)
1. **אם `gendered=false`** (אף שפה לא מפצלת) → השורה **ניטרלית**. אין מגדר להכריע.
   ודא ש-fV==mV; אם fV בלשון-נקבה בטעות → תקן לניטרלי/זכר-ברירת-מחדל.
2. **אם `gendered=true`** → חובה להכריע (לפי הניואנס למעלה). קרא את `split_langs` ב-`refs`:
   - **ציר נמען/שחקן** (`ar` تستمرين↔تستمر · `ru` -ла↔-л · `pl` -łaś↔-łeś ·
     `cs` -á↔-ý · `fr`/`es`/`it` -ée↔-é / -a↔-o): אם השפות מפצלות בין fV/mV על
     *פנייה* → זה מגדר-**שחקן** → עברית: `את...` (fV) / `אתה...` (mV).
   - **ציר מושא** (השפות מראות מגדר אבל **זהה** ב-fv ו-mv שלהן, או השורה מדברת
     על גוף שלישי): מגדר-**מושא קבוע** → עברית זהה ב-fV ו-mV, לפי מגדר ה-NPC/חפץ
     (זכר/זכרים/נקבה/נקבות/חפץ/חפצים/מעורב).
   - **רבים**: אם ru/pl/cs/es מראים ריבוי (не/-cie/-áis, ustedes) → עברית ברבים.
3. **קונצנזוס-יתירות**: ככל שיותר שפות ב-`split_langs` מסכימות → הכרעה חסינה יותר.
   אם שפות **חלוקות** על הציר → סמן `uncertain` (עובר לאימות-יריב + עין-אנוש).
4. **אורקל-ערבית** (`ar`) הקרוב-לעברית: أنتِ/أنتَ = את/אתה; ـة נקבה. עדיפות גבוהה.

## ב. הכרעת משמעות (הציר שמצמצם את השטח-העיוור)
1. קרא את **כל** ה-`refs`. אם כולן מתכנסות למשמעות אחת → ודא שהעברית תואמת.
2. **פוליסמיה** (כמו `FENCE`: גדר פיזית מול סוחר-גנוב — ראה pk=1273): כשהשפות
   **חלוקות** על המשמעות → בחר את הקריאה שמתאימה **להקשר CP2077** (שם-חנות =
   סוחר-גנוב). ציין איזו שפה תמכה בהכרעה.
3. **key-mismatch** (כמו `IGNORE, TO BE DELETED` → טקסט שגוי לגמרי, pk=13799):
   אם רוב השפות שומרות דמה/מקור והעברית מכילה טקסט אחר → דגל `wrong_text`.
4. **אורך/משמעות** ("התפרצויות" במקום "טוען"): אם העברית ארוכה/שונה מהותית
   מהקונצנזוס → תקן למשמעות הנכונה.
5. פספוס-משמעות אפשרי **רק אם כל 18 השפות מסכימות עם העברית השגויה** — נדיר;
   תרגומי-קהילה (כשייאספו) מצמצמים עוד.

## ג. שגיאות-לוואי (דטרמיניסטי — מה-`det`)
- `niqqud` → הסר ניקוד. `foreign` → הסר כתב-זר.
- `brace_dropped` → החזר את התוקן `{int_0}`/`{VALUE}` במקומו.
- `leading_latin` → אות-אנגלית בתחילת משפט מעורב → הוסף `‏` (RLM) בראש
  לכפיית בסיס-RTL (רק כשזה משפט מעורב, לא תווית-מותג).
- `english_run` → אנגלית/תעתיק-לטיני באמצע עברית → תרגם לעברית (אלא אם מותג).

## ד. מימדי-מנוע (השכבה הטכנית — משחק ≠ טקסט בלבד)
תגית `engine` בכל שורה. **בלי אלה אין 100% דיוק** — הבלשנות לבד לא מספיקה.
- **`vars`** (משתנים מוזרקים `{int_0}`/`{stat_0}`/`{Name}`): חייבים לשרוד verbatim.
  🔑 **בעיית-ההזרקה**: המנוע מזריק ערך שמגדרו/מספרו **לא ידוע בזמן התרגום** → נסח את
  העברית **סביב** המשתנה בצורה ניטרלית (לא "ה{ITEM} שבור/ה" — אלא ניסוח שעובד לשניהם).
- **`number_inject`** (`{int_0}`/`%d` + שם-עצם נספר): **חוקי-ריבוי עבריים** ≠ אנגלית
  (יחיד/זוגי/רבים/ספירה: "תפוח אחד · שני תפוחים · 5 תפוחים"). ודא שהצורה עובדת לכל N.
- **`name_inject`** (`{Name}`/`{Surname}`): נסח ניטרלי סביב שם-השחקן.
- **`line_breaks`** (מספר `\n`): שמור **בדיוק** את מספר ירידות-השורה הכפויות.
- **`overflow_risk`** (אורך): העברית ארוכה מהשפה-הארוכה-ביותר של המשחק → **סכנת שבירת-ממשק**;
  קצר את הניסוח. (פרוקסי — המסך הותאם לכל שפות המשחק.)
- **`lore_terms`** (מועמד — ראיה בלבד): מונח שנשמר זהה ב-≥6 שפות = שם-עצם/מונח-עולם →
  שמור בעברית (תעתיק/לטיני). ⚠️ רועש (תופס מילים-נפוצות) — הסוכן מכריע אם זה באמת מונח-עולם
  (LORE) או מילה רגילה; מבחין `V darkness` = חושך רגיל מול שם-קסם/כת.
- **`NPC_REL` / משלב** (סוכן): יחסי-הדמויות (אח/מפקד/אויב/זר) קובעים את המשלב; ראיה = פיצול
  vous/du בשפות. **LIP_SYNC = לא רלוונטי** (מוד-טקסט; הדיבוב האנגלי נשמר).

## פלט לכל שורה
```json
{"id":..., "verdict":"ok|fix",
 "he":["<fV>","<mV>"],          // רק אם fix; אחרת השמט
 "reason":"gender-addressee|meaning-polysemy|wrong-text|niqqud|...",
 "evidence":"ru:-ла / pl:-łaś"} // איזו שפה הכריעה
```

## כללי-ברזל (מונוטוני + anti-cheat)
- **מונוטוני**: תקן רק פגם אמיתי; אם השורה נכונה → `verdict:ok` (אל תדרדר).
- **anti-cheat**: כל `fix` חייב `reason`+`evidence`; שורה מסומנת reviewed רק עם פלט אמיתי.
- **תוקנים**: `{int_0}` וכו' — multiset זהה בין en ל-he. `~n~`/`\n` נשמרים.
- **סוג-1 שמות/מותגים** (Arasaka, NCPD, שמות-רכב) → נשארים לטיניים.
- **V** בתוך פרוזה = לטיני; שורת-שם-דובר בודדת = "וי".

## אימות-יריב (שכבה 3)
כל `fix` + מדגם מ-`ok` → סוכן שני עצמאי בודק מול אותו `refs`, ברירת-מחדל דחייה.
