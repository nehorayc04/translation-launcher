  ה. **מחק את `qa_fixes.json`** (כדי שלא יחול שוב בבאטץ' הבא), ומיד חזור לשלב א'. עד "QA done!".

## מה לתקן (אלה סוגי השגיאות — תפוס אותם!)
============================================================
**1. מילה עברית משובשת / מומצאת (הכי חשוב!)** — "מילה" שאינה קיימת בעברית, ג'יבריש, שיבוש.
   דוגמאות אמיתיות שנמצאו:
   - `מטומבגים` → צריך `מטומטמים` (idiotic)
   - `מה הזאמור` → צריך `מה לעזאזל` (what the fuck)
   - `נשק התשית ההרסני` → "תשית" אינה מילה; "collateral damage" = `נזק היקפי`
   - `כבר נשואים` עבור "for ages" → צריך `כבר המון זמן` (בלבול ages↔married)
   אם אתה רואה מילה שאתה לא מזהה כעברית תקנית — תקן אותה.

**2. תרגום-שגיאה (משמעות שונה מהמקור):**
   - `My guess is` → לא `אני שומע` (=hearsay); צריך `הניחוש שלי` / `אני מניח ש`
   - `naming names` → לא `להשמיץ שמות`; צריך `לנקוב בשמות`
   - היפוך זמן/נושא: `You have been reported` (אתה דוּוחת) → לא `נדווח` (עתיד/אישי).
   - `I'll get arrested too` (אֵיעצר) → לא `אני אעצור` (=אעצור מישהו).

**3. דליפת אנגלית:** מילה אנגלית רגילה שנשארה באמצע עברית וצריך לתרגם (לא שם פרטי/מותג).

## שמירת תגים וירידות-שורה (qa_merge מאמת — חובה)
============================================================
התיקון שלך **חייב לשמור בדיוק** את אותם תגים/placeholders ואת **ירידות-השורה** שיש בשורה הקיימת:
```
[HACK] [hacker] [laughs] [CSS_END] [PlayerName] [ONO AH]   ← כל [TOKEN] (גם קטן) — as-is
{threshold} {VALUE}                                         ← as-is
%d %s %ls %%                                                 ← אותו מספר, as-is
&#xA; &amp; &gt;                                             ← ישויות — as-is
\n                                                          ← שני התווים backslash+n — שמור אותם בדיוק (אותו מספר, אותו מיקום)
```
אם המספר/הסוג לא תואם לשורה הקיימת → qa_merge ידחה. תקן והרץ שוב. **אסור ניקוד. רק עברית+לטינית.**
