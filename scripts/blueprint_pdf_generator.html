קטגוריה 1: הארכיטקטורה בקצרה

אנחנו מחברים 3 שכבות מנצחות למערכת אחת:

graph LR UI["🎨 שכבה 1: UI מעוצב
(React / WinUI 3 / Living Glass)"] <--> CS["⚡ שכבה 2: C# System Host
(חומרה, TDP, בקר, חסימת חלונות)"] CS <--> PY["🐍 שכבה 3: Python Game Lab
(הזרקת תרגומים, מודים, צי AI)"]
  • C# Host (מערכת וחומרה): אחראי על TDP, מאווררים, בקרים וחסימת חלונות קופצים.
  • Python Service (מנוע התרגום): מריץ את כל מזרקי הקבצים של TranslationManager (bsa.py, forge.py, swf.py, Oodle) וצי ה-AI.
  • Frontend UI (ממשק זכוכית): עיצוב מודרני (Living Glass) עם תמיכה מלאה בעכבר, מסך מגע ובקר.

קטגוריה 2: ביצועים ומהירות שיא (Extreme Performance)
graph TD RAM["🧠 1. הקפאת RAM בזמן משחק
(ירידה ל-פחות מ-20MB RAM)"] IPC["⚡ 2. Shared Memory IPC
(תקשורת מהירה מ-2ms)"] IO["🏎️ 3. Direct I/O Async Patcher
(הזרקת תרגום ב-3 שניות)"] NPU["👁️ 4. Offline NPU OCR
(תרגום מסך ללא ירידת FPS)"] RAM --- IPC --- IO --- NPU
  1. 1
    הקפאת RAM בזמן משחק: כשהמשחק נפתח, התוכנה משחררת זיכרון ויורדת ל-פחות מ-20MB RAM. כשהמשחק נסגר, היא חוזרת ב-0.1 שניות!
  2. 2
    תקשורת מהירה (Shared Memory IPC): מעבר נתונים בתוך ה-RAM בפחות מ-2 מילי-שניות.
  3. 3
    הזרקה ב-3 שניות (Direct I/O): התקנת תרגום ענקי של 100GB מתקצרת מ-45 שניות ל-3 שניות בלבד!
  4. 4
    תרגום מסך ב-NPU: תרגום בלייב על מאיץ ה-AI המקומי — 0% פגיעה ב-FPS ובכרטיס המסך!
