# The Witcher 3 — תיקון מגדר (385 שורות) מול הערבית של המשחק

התרגום הראשי נעשה מאנגלית — שמאבדת מגדר — אז המגדר נוחש (בד"כ זכר).
לכל שורה כאן יש את ה**ערבית המקורית של המשחק**, שמסמנת בבירור את מגדר ה**נמען**.
המשימה: לתקן את ה**עברית** כך שמגדר הפנייה יתאים לערבית — **בלי לשנות שום דבר אחר**.

עולם המכשף (וויצ'ר): גראלט, סירי, ינפר, נילפגארד, נוביגרד.

## הלולאה (חזור עד "All done!")
```
python get_batch.py 60      # כותב current_batch.json = {id: {en, he, ar, target}}
# ערוך כל ערך: החלף אותו במחרוזת העברית המתוקנת (רק המגדר)
python merge_batch.py       # מאמת + ממזג ל-fixed.json
```

## מה לעשות בכל שורה
- `he` = העברית הנוכחית (מגדר שגוי). `ar` = הערבית (אמת). `target` = מגדר הנמען: `f`=נקבה, `m`=זכר.
- שכתב את `he` כך שהפנייה תהיה ב`target`:
  - נקבה: `אתה→את` · `שלך(ז)→שלך(נ)` · פעלים: `תוכל→תוכלי` · `קח→קחי` · `תן→תני` · `חושב→חושבת` · `יודע→יודעת` · `רוצה(פנייה)→רוצה` (זהה) · `לך→לכי` (רק כשזה "go", לא "אליך").
  - זכר: ההפך.
- **שנה רק מורפמות מגדר של הפנייה.** אל תיגע ב: משמעות, שמות, מספרים, תגים/placeholders (`<i>`,`</i>`,`<br>`,`<font..>`,`{..}`,`%d`,`&ent;` — בדיוק אותו מספר ואותו סוג), פיסוק.
- **false-alarm?** לפעמים המגדר של הנמען כבר **נכון**, וה"זכר" שסומן הוא בעצם פועל בגוף **ראשון** (הדובר: "אני מדבר", "אני יודע") או **שלישי** — לא הפנייה. במקרה כזה כתוב בדיוק `SKIP` (merge יסמן אותה כבוצעה בלי לשנות).
- אם השורה בגוף שלישי בלבד (אין פנייה ישירה לנמען) — כתוב `SKIP`.
- **בלי אף אות ערבית** בתוצאה, בלי ניקוד.

## סיום
merge_batch דוחה שורה שהמגדר בה עדיין לא תואם / שינתה טוקן / הכניסה ג'יבריש — היא תחזור בסבב הבא.
כשמודפס **"All done!"** — סיימת. אל תיגע ב-`to_fix.json` ובאף קובץ אחר.
