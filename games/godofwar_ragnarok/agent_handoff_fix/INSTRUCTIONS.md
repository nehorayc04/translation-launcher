# GoWR — תיקון 313 כתוביות דיאלוג שלא תורגמו (מהערבית)

**רקע:** במוד העברי של God of War: Ragnarök נמצאו **313 שורות דיאלוג** שלא תורגמו —
הן מוצגות במשחק בערבית (המקור המקצועי של המשחק) ולכן נראות לשחקן כטקסט "מוזר/מכורסח".
המשימה: לתרגם אותן **מהערבית לעברית**. אין להן מקור אנגלי, אז **הערבית היא המקור** (זו
הלוקליזציה הרשמית של המשחק — תרגום מדויק ממנה = הטקסט הנכון).

## הלולאה (חזור עד "All done!")
```
python get_batch.py 60      # כותב current_batch.json = { id: {"ar": <ערבית>, "he": ""} }
# מלא את "he" בכל פריט (תרגום עברי של ה-"ar")
python merge_batch.py       # מאמת + ממזג ל-done_translate.json; דוחה שורה לא-תקינה
```
כשמופיע "All done!" — סיימת. (313 שורות בסך הכול.)

## כללים נוקשים
1. **תרגם את הטקסט הנראה בלבד לעברית טבעית וזורמת** (דיאלוג של משחק, רגיסטר נורדי/דרמטי).
2. **שמור מילה-במילה** (העתק, אל תתרגם):
   - את קידומת ה-cue בתחילת השורה: `[[S:SPEAKER:clip:timing:hash]]` (למשל
     `[[S:ATREUS:vo_int9_lvl_mid1a_s095_010_son:50-...]]`) — **בדיוק כפי שהיא**.
   - `\n` (שבירת שורה — אותו מספר כמו במקור), `[style=Highlight]`/`[/style]`, `[i]`/`[/i]`,
     `%d`, `[Icons:...]`, `[HeavyAttackButton]` וכל `[...]`.
3. **שמות נשארים** (תעתיק עברי מקובל, לא לתרגם משמעות): Kratos=קרייטוס, Atreus=אטראוס,
   Odin=אודין, Thor=ת'ור, Faye=פאי, Freya=פרייה, Mimir=מימיר, Sindri/Brok/Tyr/Angrboda…
4. **מגדר:** הערבית מסמנת מגדר — שמור אותו. `أنتَ`=אתה, `أنتِ`=את, `أحسنتَ`=כל הכבוד (לזכר),
   `أحسنتِ`=כל הכבוד (לנקבה), פועל בנקבה (ـين) → נקבה בעברית.
5. **בלי ניקוד. בלי להשאיר אותיות ערביות** בפלט (הכל עברית + טוקנים לטיניים).
6. אל תמציא/תשמיט תוכן. אל תיגע ב-`to_translate.json` (מקור בלבד) — רק ב-`current_batch.json`.

## אנטי-רמאות (ה-merge דוחה אוטומטית)
שורה תידחה אם: אין בה עברית · נשארו אותיות ערביות · הושמט ה-cue · מספר `\n` שונה מהמקור.
שורה שנדחתה תוגש שוב בבאצ' הבא — תקן אותה.
