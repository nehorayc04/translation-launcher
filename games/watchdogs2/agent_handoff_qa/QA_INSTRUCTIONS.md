## מה לתקן
============================================================
**1. מילה עברית משובשת / מומצאת (הכי חשוב!)** — "מילה" שאינה עברית תקנית, ג'יבריש, בלבול.
   דוגמאות אמיתיות מהמשחק:
   - `בסטנים` → `בסשנים` (sessions)
   - `מה הזאמור` → `מה לעזאזל`
   - `נשק התשית ההרסני` → "תשית" לא מילה; "collateral damage" = `נזק היקפי`
   - `כבר נשואים` עבור "for ages" → `כבר המון זמן` (בלבול ages↔married)
   - `נקודות הגובה` עבור "high points" → `הנקודות הגבוהות` (גובה↔גבוה)
   אם אתה רואה מילה שאינך מזהה כעברית תקנית — תקן.

**2. תרגום-שגיאה (משמעות שונה מהמקור):** הקפד על דקדוק, זמן, ונושא נכונים.

**3. דליפת אנגלית (`ENGLISH_LEAK`):** מילה אנגלית רגילה (אות קטנה) שנשארה באמצע עברית
   וצריך לתרגם (לא שם פרטי/מותג). תרגם אותה ואם צריך — נסח את המשפט מחדש.

**4. לא מתורגם (`UNTRANSLATED`):** שורה שכולה אנגלית → תרגם לעברית מלאה. **אבל** שם
   פרטי/מותג/קוד/ראשי-תיבות נשארים בלטינית (ראה למטה) — אם זה רק שם, השאר כמו שהוא.

**5. שמות מקומות (`PLACENAME`) — עקביות + דיוק (חובה לפי הטבלה):**
   שמות מקומות אמיתיים חייבים להיות **זהים בכל המשחק** ולפי השם העברי הקנוני. השתמש
   **בדיוק** בטבלה ב-`glossary.json` (נטענת בנפרד). אם השם תורגם אחרת/שונה במקום אחד —
   החלף לצורה הקנונית. (לדוגמה: "Bay Area" צריך להיות זהה בכל מקום, "Golden Gate Bridge"
   = "גשר שער הזהב" וכו'.)

**6. ארוך מדי (`OVERFLOW`):** השורה נחתכת על המסך כי העברית ארוכה מהאנגלית. **קצר** את
   העברית למשפט תמציתי באותה משמעות, באורך דומה לאנגלית (אל תוסיף מילים מיותרות).

## שמירת טוקנים וירידות-שורה (qa_merge מאמת — חובה)
============================================================
התיקון **חייב לשמור בדיוק** את אותם טוקנים/placeholders ואת ירידות-השורה שיש **באנגלית**:
```
[HACK] [hacker] [laughs] [HACKERSPACE] [PlayerName]   ← כל [TOKEN] (גם קטן) — as-is
{threshold} {VALUE}                                    ← as-is
%d %s %ls %%                                            ← אותו מספר, as-is
&#xA; &amp; &gt;                                        ← ישויות — as-is
\n                                                     ← שני התווים backslash+n — שמור (אותו מספר)
```
אם המספר/הסוג לא תואם למקור → qa_merge ידחה. **אסור ניקוד. רק עברית+לטינית.**
