## הלולאה (חזור עליה שוב ושוב)
```
python get_batch.py
```
→ כותב `current_batch.json` עם ~500 מחרוזות אנגלית `{ "English": "" }`
   (או מדפיס `All done!` = סיימת, עצור).

1. פתח `current_batch.json`, **תרגם בעצמך** כל ערך לעברית, ומלא אותו במקום:
   `{ "English source": "התרגום העברי שלך" }` (ה-**key** נשאר האנגלית; הערך = העברית).
2. הרץ:
   ```
   python merge_batch.py
   ```
   → מאמת + ממזג ל-`hebrew.json`. אם הוא מדפיס בעיות (`TOKEN MISMATCH`/`EMPTY`/...),
     **תקן רק את אותן שורות** ב-`current_batch.json` והרץ שוב `merge_batch.py`.
3. **מיד** חזור לשלב הראשון (`python get_batch.py`) — בלי לעצור, בלי לדווח.

**עשה כמה שיותר סבבים בכל תור.** אל תכתוב לי "סיימתי batch" ותחכה — פשוט תריץ
`get_batch.py` שוב ותמשיך. **להמשך אחרי עצירה/סוכן חדש:** פשוט הרץ `python get_batch.py`
— הוא מדלג אוטומטית על מה שכבר תורגם וממשיך מהמקום הנכון.

⚠️ **JSON תקין — חובה:** כל `"` בתוך טקסט חייב escape כ-`\"`. בלי מרכאות חכמות.
