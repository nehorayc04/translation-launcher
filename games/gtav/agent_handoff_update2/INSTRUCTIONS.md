# הנחיה לסוכן — תרגום GTA V לעברית (זרימה רזה: רק מתרגמים)

**המשימה שלך = רק לתרגם.** בלי get_batch, בלי merge, בלי skip, בלי סקריפטים. חילקתי מראש את כל הטקסט
לקבצי-chunk ממוספרים. אתה פשוט קורא קובץ אנגלית, מתרגם, וכותב קובץ עברית. זהו.

תיקיית chunks:  `C:\Users\Nehoray_Cohen\Projects\Game translator\games\gtav\agent_handoff_update2\chunks\`
יש שם `en_000.json` עד `en_136.json` — כל אחד `{ "key": "English" }` עם 300 מחרוזות.

================  מה לעשות  ================
עבור על הקבצים **לפי הסדר** (en_000, en_001, ...). לכל קובץ:
1. קרא את `chunks/en_NNN.json`.
2. תרגם בעצמך את כל 300 הערכים לעברית.
3. כתוב `chunks/he_NNN.json` באותו פורמט בדיוק: `{ "key": "התרגום העברי שלך" }` (אותם keys).

**עשה כמה שיותר קבצים בכל תור** (כל קובץ = קריאה + כתיבה = 2 פעולות בלבד; כך תספיק הרבה). אל תעצור
לדווח באמצע — פשוט תמשיך לקובץ הבא.

**להמשך אחרי עצירה:** הסתכל אילו `he_NNN.json` כבר קיימים, והמשך מה-`en_NNN` הראשון שאין לו `he_NNN`.
(למשל אם קיים `he_004.json` אבל לא `he_005.json` — התחל מ-`en_005`.) **סיימת רק כשיש `he_NNN` לכל
`en_NNN` (000 עד 136).**
