# משימת תרגום — The Last of Us Part II Remastered → עברית

אתה מתרגם את הטקסט של המשחק **The Last of Us Part II Remastered** מאנגלית לעברית. עבודה
עצמאית: לולאה של קבל־מנה → תרגם → מזג → חזור, עד שמסיימים. **אל תעצור באמצע לשאול — בצע עד הסוף.**

## הלולאה (הרץ מתוך תיקיית `agent_handoff/`)

```
python get_batch.py            # מנה של ~250 מחרוזות -> batch_0.json  (עם agent יחיד)
# מלא כל "he" ב-batch_0.json בעברית (ראה כללים) ושמור
python merge_batch.py          # מאמת + ממזג ל-hebrew_0.json, מדווח דחיות
# חזור, עד ש-get_batch מדפיס "All done for this slot!"
```

**N סוכנים במקביל (בלי התנגשות):** כל סוכן מקבל slot נפרד —
`python get_batch.py <slot> <N>` ואז `python merge_batch.py <slot>` (slot ב-0..N-1).
החלוקה לפי md5 של המפתח, אז השטחים זרים לחלוטין.

## פורמט המנה
`batch_<slot>.json` = `{ "<key>": {"en":.., "cat":.., "ru":.., "es":.., "fr":.., "gender":.., "he":""} }`.
תמלא **רק** את השדה `"he"`. אל תיגע בשאר השדות ואל תשנה מפתחות.

**המנות מגיעות לפי קטגוריות** (`cat`) בסדר נראוּת: קודם **ממשק ותפריטים** (ממשק/תפריטים/נגישות —
קצר, תקני), אחר כך **כתוביות עלילה** (דיאלוג — עברית מדוברת טבעית), ולבסוף **דיבורי רקע** (barks).
כך החלק הכי נראה מסתיים ראשון. השתמש ב-`cat` כדי לכוון את הרגיסטר.

**`ru`/`es`/`fr` = הטקסט של המשחק עצמו בשפות ממוגדרות — זה מקור המגדר, לא לנחש מאנגלית.**
אנגלית לא מבחינה זכר/נקבה; רוסית כן (עבר: `-л` זכר / `-ла` נקבה; `ты`=אתה/את יחיד,
`вы`=אתם/מנומס). קרא אותם כדי לבחור את המגדר הנכון בעברית. `gender` = רמז מוכן
(נמען/דובר/רפרנט) כשהצלחנו לגזור אותו אוטומטית. (לא כל שורה צריכה מגדר — רק היכן שהעברית מטה.)

## כללי הזהב

1. **עברית לוגית (סדר קריאה טבעי) — לא הפוכה.** כתוב עברית רגילה כמו שקוראים.
   ה-build הופך אותה ל-RTL ויזואלי אוטומטית. **אל תהפוך אותיות בעצמך.**
2. **שמר כל token בדיוק כמו במקור, verbatim** (אותו מספר, אותו כתיב, במיקום המתאים):
   - תגי עיצוב: `<font ...>...</font>` · `<br>` · `<break/>` · `<hang>`/`</hang>` (השאר את
     הטקסט בתוך הזוג — תרגם רק את הטקסט, לא את התג).
   - איי-glyph/משתנה: `|gen:interact|` · `|menu:select|` · `|l3|` · `|@01|` · `[A]` · `[TEXT]` ·
     `%d`/`%s`/`%.1f` · `{value}` · `&amp;`/`&lt;` וכו'.
   - ירידת שורה literal `\n` — השאר במקומה (עברית משני צדיה).
3. **בלי ניקוד** אף פעם.
4. **בלי כתב זר** — עברית + לטינית (לשמות/מותגים) בלבד. בלי ערבית/קירילית/CJK.
5. **שמות פרטיים / מותגים / קודים — נשארים באנגלית** (Ellie, Abby, WLF, Seraphites...);
   ראה מילון למטה לשמות שיש להם צורה עברית מקובלת. מחרוזת שכולה שם/קוד — מותר להשאיר לטינית.
6. **אל תשאיר אנגלית על משפט אמיתי** (משפט עם 2+ מילים באנגלית שאינן שמות) — זו רמאות והמערכת
   תדחה אותה. תרגם באמת.
7. **רגיסטר:** דיאלוג = עברית מדוברת טבעית וחיה (משחק פוסט-אפוקליפטי אפל, דמויות מדברות אנושית,
   כולל קללות בוטות ורגש עז). ממשק/תפריטים/נגישות = קצר, תקני, ברור. שמור על הטון של המקור.
8. **מגדר — קרא את `ru`/`es`, אל תנחש.** כשהמשפט תלוי מגדר (אתה/את, מוכן/מוכנה, לך/לכי):
   הרוסית מכריעה — `ты ... -л` (сделал) = זכר, `-ла` (сделала) = נקבה, `вы` = רבים/מנומס;
   הספרדית/צרפתית לרפרנט (`listo`/`lista`). זה מקור המגדר של המשחק — עדיף על ניחוש מאנגלית.
   שים לב: אלי ואבי הן **נשים** — פנייה אליהן/דיבור שלהן בגוף ראשון = נקבה, אלא אם הרוסית מכריעה אחרת.

## בקרה
- `python qa_scan.py` — סורק את כל מה שתורגם ומדווח כשלים מבניים + כיסוי. הרץ מדי פעם.

  היא חוזרת ב-`get_batch` הבא עד שתתוקן. **אסור לרמות** (למלא אנגלית / לדלג עם `he`==`en`).
