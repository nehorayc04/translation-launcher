# מנוע ביקורת + תרגום רב-לשוני — אוניברסלי לכל משחק (עידן חדש)

מנוע גנרי אחד שעובד על **כל משחק** — מתורגם (מצב **ביקורת**) או שעדיין לא תורגם (מצב **תרגום**).
המנוע `universal/multilang_review.py` הוא game-agnostic לחלוטין; כל משחק מספק רק **מתאם דק**
שבונה את הקלט המנורמל. Claude בונה+מאמת, **לא מתרגם** ([[delegate-all-translation]]).

עץ-התרחיש המלא: `עץ_תרחיש_ביקורת_רב_לשונית.html` (בשורש הפרויקט).

---

## 1. חוזה-המתאם (מה כל משחק חייב לספק)
כל משחק כותב סקריפט דק (`games/<game>/.../build_multilang.py`) שבונה **שני מבנים מנורמלים**
בקודי-שפה קנוניים, ואז קורא ל-`multilang_review.build(...)`:

```
panel : dict   id -> { lang: [femaleVariant, maleVariant] }   # כל שפות המשחק, כולל "en"
spine : dict   id -> (section, order, he_fv, he_mv)            # העברית; he_* ריק => מצב תרגום
```

- **`id`** — מזהה השורה (primaryKey / stringId / כל מפתח יציב), כמחרוזת.
- **`panel[id][lang]`** — הצמד `[נקבה, זכר]` מכל שפה שהמשחק מספק. השוני `fv!=mv` בין שפות הוא
  מה שמזהה **דטרמיניסטית** שהשורה תלוית-מגדר (ערובת אי-הפספוס).
- **`spine[id]`** — העברית הנוכחית. אם `he_fv==he_mv==""` → השורה במצב **תרגום** (משחק חדש);
  אחרת מצב **ביקורת** (משחק מתורגם). אפשר לערבב מצבים באותו קורפוס.
- **קודי-שפה קנוניים** (המתאם ממפה את שמות-התיקיות של המשחק לאלה):
  `en ar ru pl cs es es-mx fr it pt de ja ko zh-cn zh-tw tr th hu uk`
  (המנוע מקבל גם וריאנטים כמו `es-es`/`es-419` בזיהוי המשלב).

**מקור המשחק לכל שדה** (לפי הפורמט של כל מנוע):
- `panel` = חילוץ + סריאליזציה של כל ארכיוני-השפה של המשחק (CR2W / PSARC / forge / WAD / …)
  → צמד fv/mv לכל שפה, לפי מזהה משותף.
- `spine` = ה-Hebrew spine של המשחק (אם קיים) + `section`+`order` לסדר-נראות. משחק חדש → spine
  מ**מרחב-המפתחות** של המשחק עם fv=mv="".

## 2. מה המנוע מייצר (הסוכן צורך — בלי חיפושים נוספים)
`build(kind, panel, spine, out_dir, cfg)` → `<out_dir>/<kind>.final.jsonl`, שורה לכל פריט:
```
id           section:pk
kind         onscreens | subtitles | ui | dialogue | ...
mode         review | translate           # יש עברית / אין עברית
en           מקור אנגלי
refs         { שפה: [fv, mv] }            # כל שפות המשחק
he           [fv, mv]                     # העברית הנוכחית (ריק במצב תרגום)
gendered     bool                          # איחוד השפות שמפצלות fv!=mv (חלוקה דטרמיניסטית)
split_langs  השפות שמפצלות מגדר + הצורות
he_split     האם העברית עצמה מבחינה מגדר
det          { niqqud/foreign/brace_dropped/leading_latin/english_run }
tags         { axis[P2/P1?], player_gender, formality, number, imperative, hom_candidate }
engine       { vars, number_inject, name_inject, line_breaks, overflow_risk, lore_terms }
```

## 3. מודל 3 הסוגים (הגדרת המשתמש → מיפוי למנוע)
המנוע בוחר **fV** לשחקנית, **mV** לשחקן. `mV` ריק = "השתמש ב-fV".
- **סוג 1 — UI** (משימות/מטרות, פקודות, תיאורים, מגילות, שמות-חפצים): **ניטרלי.**
  fV==mV, זכר-כברירת-מחדל לפקודות. חריג: מטרת-משימה שפונה לשחקן *יכולה* להיות מגודרת.
- **סוג 2 — השחקן מדבר**: על עצמו → לפי מגדר-השחקן (fV/mV), **אין רבים**;
  על NPC/חפץ → מגדר-המושא **קבוע** (זהה ב-fV ו-mV).
- **סוג 3 — NPC מדבר**: על השחקן (fV/mV) או על NPC (מגדר-מושא קבוע).

## 🔑 ניואנס-מפתח: "שפה מפצלת" ≠ "עברית חייבת לפצל"
הערבית מגדרת אפילו פקודות-UI (`Interact`→تفاعلي/تفاعل). לכן `gendered=true` הוא **טריגר לביקורת**,
אבל התשובה תלויה ב**סוג**: סוג-1 → עברית **ניטרלית** (fV==mV) גם אם שפות מפצלות; סוג-2/3 (פנייה
לשחקן) → עברית **מפצלת** (fV="את..." / mV="אתה...").

## 4. הכרעת מגדר (הציר שמבטיח וודאות)
1. `gendered=false` → השורה **ניטרלית**; ודא fV==mV.
2. `gendered=true` → הכרע לפי `split_langs`:
   - **ציר נמען/שחקן** (ar أنتِ/أنتَ · ru -ла/-л · pl -łaś/-łeś · cs -á/-ý) → פנייה מגודרת →
     עברית `את...`(fV) / `אתה...`(mV).
   - **ציר מושא** (השפות מגדרות אך זהה ב-fv/mv שלהן, או גוף שלישי) → מגדר-מושא **קבוע**,
     עברית זהה ב-fV/mV לפי מגדר ה-NPC/חפץ.
   - **רבים** (ru/pl/cs/es מראים ריבוי) → עברית ברבים.
3. קונצנזוס-יתירות: יותר שפות מסכימות → הכרעה חסינה יותר. שפות חלוקות → `uncertain` → אימות-יריב.
4. **אורקל-ערבית** (`ar`) הקרוב-לעברית: أنتِ/أنتَ = את/אתה; ـة נקבה. עדיפות גבוהה.

## 5. הכרעת משמעות
1. קרא את **כל** ה-`refs`. כולן מתכנסות → ודא שהעברית תואמת.
2. **פוליסמיה** (FENCE: גדר מול סוחר-גנוב): שפות חלוקות → בחר את הקריאה שמתאימה להקשר המשחק;
   ציין איזו שפה תמכה.
3. **key-mismatch**: רוב שפות שומרות דמה/מקור והעברית מכילה טקסט אחר → `wrong_text`.
4. **אורך/משמעות** ("התפרצויות" במקום "טוען"): עברית שונה מהותית מהקונצנזוס → תקן.
5. תרגומי-קהילה (כשייאספו) מצמצמים עוד את השטח-העיוור.

## 6. שגיאות-לוואי (דטרמיניסטי — מ-`det`)
`niqqud`→הסר · `foreign`→הסר כתב-זר · `brace_dropped`→החזר תוקן במקומו ·
`leading_latin`→הוסף `‏`(RLM) בראש משפט-מעורב (לא תווית-מותג) · `english_run`→תרגם (אלא אם מותג).

## 7. מימדי-מנוע (השכבה הטכנית — משחק ≠ טקסט בלבד; מ-`engine`)
- **`vars`** ({int_0}/{stat_0}/{Name}) — חייבים לשרוד verbatim; נסח **סביב** המשתנה בניטרליות
  (המגדר/מספר של הערך המוזרק לא ידוע בזמן התרגום).
- **`number_inject`** (%d + שם-עצם נספר) — **חוקי-ריבוי עבריים** (יחיד/זוגי/רבים); ודא לכל N.
- **`name_inject`** ({Name}/{Surname}) — ניסוח ניטרלי סביב השם.
- **`line_breaks`** — שמור **בדיוק** את מספר ה-`\n`.
- **`overflow_risk`** — עברית ארוכה מהשפה-הארוכה-ביותר → סכנת שבירת-ממשק; קצר.
- **`lore_terms`** (ראיה בלבד — רועש) — מונח שנשמר ב-≥6 שפות = שם-עצם/מונח-עולם → שמור; הסוכן מכריע.
- **LIP_SYNC = לא רלוונטי** (מוד-טקסט; דיבוב אנגלי נשמר).

## 8. אמינות התגים (נמדד — בלי אמון עיוור)
- **אמין (סומך):** `gendered`/`split_langs` (~99.97% נקי), `axis`, `imperative`, `det`, `engine`.
- **ראיה-בלבד (הסוכן מכריע):** `hom_candidate` (רובו מילים-נרדפות), `formality` (מוסכמת-משלב
  של שפה בודדת, לא משלב-השורה), `lore_terms`. קרא את כל ה-`refs` והכרע.

## 9. פלט לכל שורה
```json
{"id":..., "verdict":"ok|fix", "he":["<fV>","<mV>"], "reason":"gender-addressee|meaning-polysemy|...", "evidence":"ar:أنتِ / ru:-ла"}
```

## 10. כללי-ברזל (מונוטוני + anti-cheat)
- **מונוטוני**: תקן רק פגם אמיתי; שורה נכונה → `verdict:ok` (אל תדרדר).
- **anti-cheat**: כל `fix` חייב `reason`+`evidence`; שורה reviewed רק עם פלט אמיתי.
- **תוקנים**: multiset זהה בין en ל-he; `\n`/`~n~` נשמרים.
- **שמות/מותגים** (סוג-1) → לטיניים. שם-הדמות בפרוזה = לטיני; שורת-שם-דובר בודדת = תעתיק.
- **אימות-יריב** (שכבה 3): כל `fix` + מדגם `ok` → סוכן שני עצמאי, ברירת-מחדל דחייה.

## 12. הוספת משחק חדש (מתאם דק)
```python
import sys, os; sys.path.insert(0, "<repo>/universal")
import multilang_review as mlr
cfg = mlr.Cfg(langs=[...game loc codes...],
              gender_langs=(...), addressee_langs=("ar","pl","cs"), speaker_langs=("ru",))
panel = build_panel()          # id -> {lang:[fv,mv]}  (חילוץ+סריאליזציה של שפות המשחק)
spine = build_spine("subtitles")  # id -> (section, order, fv, mv)   (fv=mv="" למשחק חדש)
st = mlr.build("subtitles", panel, spine, out_dir, cfg)
print(mlr.report("subtitles", st))
```
המנוע זהה למשחק מתורגם ולמשחק חדש — רק ה-spine קובע ביקורת מול תרגום.
