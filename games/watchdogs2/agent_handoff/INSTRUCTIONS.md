## הלולאה האוטונומית — חזור עד "All done!"
============================================================
**שלב 0 (פעם אחת, בהתחלה):** `python qa_scan.py`
  → סורק את כל המתורגמים, מסיר אוטומטית שורות עם **באגים מבניים** (סקריפט זר/ניקוד/תגים
    אבודים/דליפת סירוב/אורך חריג/אנגלית שלא תורגמה). השורות שהוסרו הופכות ל"לא מתורגם"
    ותעשה אותן מחדש בלולאה. זה ה**תיקון באגים** — מקופל לתוך התרגום.

> ⚠️ **זו לולאה — אסור לעצור אחרי באטץ' אחד!** כל סבב מתרגם רק 500 (או פחות). יש מאות
> מחרוזות. חזור על המחזור **שוב ושוב** עד ש-`get_batch.py` מדפיס בדיוק `All done!`. אם
> תרגמת באטץ' אחד ועצרת — **לא סיימת**. המשך עד שאין יותר.

**ואז חזור על המחזור עד "All done!":**
  א. `python get_batch.py`
     → אם מודפס `All done!` → **סיים** (עבור לשלב הסיום למטה). אחרת נוצר
       `current_batch.json` עם עד 500 המחרוזות הבאות שלא תורגמו.
  ב. `python loop_split.py`
     → מפצל ל-`batch_part1.json` .. `batch_part4.json` (125 כל אחד, `{id: english}`).
  ג. **תרגם בעצמך** כל חלק → כתוב `trans_part_1.json` .. `trans_part_4.json`
     (JSON `{id: "תרגום עברי"}`, **אותם ids בדיוק**).
     → מחרוזת **שלא ניתנת לתרגום** (ראה כלל 7 למטה) — **אל תשים אותה ב-trans_part**;
       במקום זה הוסף את ה-id שלה ל-`skip.json` (ראה הסעיף "skip.json" למטה).
  ד. `python loop_merge.py`
     → מאמת תגים + סקריפט + ניקוד, וממזג רק את הנקיים ל-`hebrew.json` (כתיבה אטומית).
     → אם מודפס `TAG MISMATCH` / `FOREIGN SCRIPT` / `NIQQUD` / `EMPTY` על id מסוים:
       **תקן רק את אותו id** בקובץ ה-trans_part שלו (התאם תגים למקור / הסר ניקוד / תרגם),
       והרץ `loop_merge.py` שוב — עד שהכול נקי וממוזג.
  ה. **מיד** חזור לשלב א'. בלי להמתין, בלי לשאול, בלי לדווח באמצע. **חזור עד "All done!".**

## skip.json — מחרוזות שלא ניתנות לתרגום (כדי שהלולאה תסתיים)
============================================================
חלק מהמחרוזות הן **שמות משתמש / כינויי hacker / גרפיטי / leetspeak / קטעי קוד / קודי שגיאה
/ שמות בשפה זרה** — אין להן תרגום עברי והן צריכות להישאר בלטינית במשחק. דוגמאות:
`rekt`, `doneGOOFED`, `http 404`, `302 forbidden`, `dedsec sux`, `xxxxxxxxxx`,
`params.bellw = true;`, `retr0@pyhooma00:~$`, `eKart07`, `4N00bs Pistol`,
`yi bi zhi li`, `Las Ondas De La Ria KODR`, `[EMOTION1]`, `[DEPLOYRCDRONE]`.

**עבור כל מחרוזת כזו:** אל תתרגם, אל תשים ב-trans_part. במקום זה **הוסף את ה-id שלה
ל-`skip.json`** — קובץ JSON שהוא **מערך של מחרוזות id**, למשל:
```json
["286775", "635683", "650955", "688524"]
```
(אם הקובץ לא קיים — צור אותו. אם קיים — הוסף ל-מערך, אל תמחק קיימים.)
`get_batch.py` מתעלם מ-ids ב-skip.json (סופר אותם כ"בוצע"), כך שהלולאה מגיעה ל-"All done!".
**הכלל:** אם אתה לא מצליח להפיק עברית אמיתית למחרוזת אחרי ניסיון כן — שים אותה ב-skip.json
ותמשיך. אל תיתקע על מחרוזת אחת ואל תכניס "תרגום" שהוא רק העתקת האנגלית.

## אימות תגים (loop_merge.py / qa_scan.py — הלוגיקה שמחייבת אותך)
============================================================
לכל id, ה-tokens חייבים להופיע **באותה כמות** במקור ובתרגום (multiset זהה). ה-tokens הם:
```
[CSS_BLUE] [CSS_RED] [CSS_END] [CSS_...]   ← תגי צבע — העתק as-is
[RELOAD] [HIDEINCAR] [SCOPE] [InteractButton] [GALLERY_DELETE] [LF] [CR] [...]   ← כל [TOKEN] באותיות גדולות — as-is
{VALUE} {ANY}        ← העתק as-is
%d %s %ls %0.2f %u %i %%   ← אותו מספר מופעים, as-is (לעולם אל תכווץ %% ל-%)
&#xA; &amp; &gt; &lt; &nbsp;   ← ישויות HTML — as-is
```
אם המספר/הסוג לא תואם → loop_merge יסרב למזג את ה-id. תקן והרץ שוב.

6. **ראשי תיבות נשארים אנגלית:** XP · GPS · HUD · FPS · AI · ID · ATM · SF · GB · MB · RAM · CPU.
7. **קוד/מספר/סמל בלי מילה אמיתית** ("TBT-7000", "336-TT", "%ls", "eKart07", "GH03DHC") —
