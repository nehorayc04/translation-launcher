# הנחיה לסוכן — תרגום הממשק (UI) של GTA V לעברית

**משימה:** לתרגם את כל מחרוזות **הממשק** של Grand Theft Auto V מאנגלית לעברית — תפריטים, HUD,
שמות נשק/רכב, כותרות משימות, טקסט עזרה, חנויות, הגדרות, התראות מערכת. **רק ממשק — בלי כתוביות/דיאלוג
מדובר בשלב הזה.** היקף: כ-**23,136** מחרוזות (קובץ `global.gxt2` של המשחק).

> אתה (הסוכן) הוא המתרגם. אתה מתרגם בעצמך, לא קורא ל-LLM אחר. עובדים בלולאה אוטומטית עד "All done!".

---

## קבצים

| קובץ | תפקיד |
|---|---|
| `to_translate.json` | **קלט** — `{ key: "English UI string" }`. ה-`key` הוא מזהה (joaat hex) — **אסור לגעת בו**. |
| `hebrew.json` | **פלט** — `{ key: "טקסט עברי" }`. נצבר אוטומטית דרך `loop_merge.py`. |
| `skip.json` | רשימת keys שנשארים באנגלית (שמות/קודים בלי מילה אמיתית). |

**אל תיגע בשום קובץ אחר.** אל תריץ build/deploy — זה התפקיד של Claude אחרי שתסיים.

---

## הלולאה (חזור עד "All done!")

```
python get_batch.py 40          # מדפיס JSON של 40 מחרוזות הבאות לתרגום
# תרגם את כל ה-values, שמור כ-batch_he.json בפורמט { key: "תרגום עברי" } (אותם keys)
python loop_merge.py batch_he.json    # מאמת + ממזג ל-hebrew.json, מדפיס כמה נשאר
# חזור. כש-get_batch מדפיס "All done!" — סיימת.
```

`loop_merge.py` דוחה אוטומטית תרגום עם token שגוי / ניקוד / אות זרה — הוא פשוט יחזור בבאטץ' הבא, אז תקן ותמשיך.

## כללים נוקשים

1. **עברית לוגית (קריאה רגילה) — לא הפוכה.** כתוב עברית רגילה משמאל-לימין בקובץ. ההיפוך-לוויזואלי
   (RTL) נעשה אוטומטית בשלב ה-build ע"י Claude. **אל תהפוך אותיות בעצמך.**
2. **שמור כל token מילה-במילה ובאותה כמות:**
   - `~r~ ~s~ ~h~ ~n~ ~a~ ~b~ ~1~ ~y~ ~g~ ~o~ ~p~ ~q~ ~w~ ~c~ ~m~ ~u~ ~italic~ ~bold~`
     (צבע/סגנון/שורה-חדשה/מספר) — **העתק כפי שהם**.
   - `~HUD_COLOUR_...~`, `~INPUT_...~`, `~INPUTGROUP_...~`, `~PAD_...~`, `~ACCEPT~`, `~BLIP_...~` — כפתורים/בליפים, **לא לתרגם**.
   - תגים `<C>...</C>`, `<font ...>`, ו-`%s`/`%d` — **לשמר בדיוק**.
   - `~n~` = שורה חדשה — שמור אותו במקום ההגיוני בעברית.
3. **בלי ניקוד.** בלי שום אות לא-עברית/לא-לטינית (קירילית/ערבית/CJK/תאית).
4. **שמות נשארים אנגלית:** Michael, Franklin, Trevor, Lester, Los Santos, Blaine County, Lifeinvader,
   Ammu-Nation, LSPD, FIB, ועוד שמות מותגים/מקומות/דמויות. אם המקור הוא **רק שם/קוד** (בלי מילת-אנגלית
   אמיתית — למשל "DLC", "60 FPS", "ISO", "GTA Online") — השאר אותו כפי שהוא והוסף את ה-key ל-`skip.json`.
5. **רגיסטר GTA:** סלנג רחוב, פשע, סאטירה על אמריקה. קללות/וולגריות — לתרגם כפי שהן במקור (אל תצנזר).
   טבעי וזורם בעברית ישראלית, לא תרגום מילולי מאולץ.
6. **מספרים ויחידות** (5, $, %, mph) — נשארים קדימה כפי שהם.

| Wanted level | דרגת מבוקש |
| Health | בריאות · Armor | שריון · Ammo | תחמושת · Stamina | סבולת |
| Wasted | חוסל · Busted | נתפס · Mission Passed | המשימה הושלמה · Mission Failed | המשימה נכשלה |
| Checkpoint | נקודת ביקורת · Respawn | תחייה · Save / Autosave | שמירה / שמירה אוטומטית |
| Mission | משימה · Heist | שוד · Objective | יעד · Reward | תגמול |
| Garage | מוסך · Safehouse | מחבוא · Property | נכס · Weapon Wheel | גלגל הנשק |
| Map | מפה · Waypoint | נקודת ציון · Quick Save | שמירה מהירה · Settings | הגדרות |
| Story Mode | מצב סיפור · GTA Online | GTA אונליין · Director Mode | מצב במאי |
| Cash / Money | מזומן / כסף · Bank | בנק · Cut (heist) | חלק · Crew | חבורה |
